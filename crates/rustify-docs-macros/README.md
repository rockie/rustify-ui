# rustify-docs-macros

Procedural site declarations for Rustify Docs.

Consumed through the rustify-docs library. Parsing is shared with rustify-docs-syntax; application code normally uses the rustify-docs site declaration API.

Use the exact registry version in your manifest:

```toml
[dependencies]
rustify-docs-macros = "=0.2.0"
```

See the [repository](https://github.com/rockie/rustify-ui) and [author guide](https://github.com/rockie/rustify-ui/blob/main/docs/docs-ssg.md).
