# rustify-docs-syntax

Shared parser for Rustify Docs site declarations.

Used by the Docs procedural macros and CLI to interpret the same site declarations on the host. It has no rendering-mode features.

Use the exact registry version in your manifest:

```toml
[dependencies]
rustify-docs-syntax = "=0.2.0"
```

See the [repository](https://github.com/rockie/rustify-ui) and [author guide](https://github.com/rockie/rustify-ui/blob/main/docs/docs-ssg.md).
