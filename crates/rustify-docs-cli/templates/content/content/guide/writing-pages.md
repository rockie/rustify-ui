# Writing pages

Every `.md` file under `content/` is a page: `content/guide/setup.md` is
published at `/guide/setup/`. Link to another page by its file, as GitHub
does: [Getting started](getting-started.md#preview-while-you-write).

> [!TIP]
> GitHub's alerts (`NOTE`, `TIP`, `IMPORTANT`, `WARNING`, `CAUTION`) and
> tables, task lists and footnotes all work here.

| File | Address |
| --- | --- |
| `content/index.md` | `/` |
| `content/guide/writing-pages.md` | `/guide/writing-pages/` |

Put images next to the page that shows them, or in `static/`.
