# cn source and generated data

The native class engine, ordered configuration compiler and validators in
`src/cn/` port behavior from cn commit
`b7ec0fce43d824a60517fab508584eb860fdf717`, package version `0.4.0`.
Its MIT notice is preserved in `LICENSE` (Copyright 2026 shadcn).
`emit-template.txt` preserves the fixed upstream compiler's table-data decoder;
the Rust compiler supplies its packed values. It is tooling output, not a JS
runtime compiler.

`tables.rs`, `config.rs` and `default-config.json` come from the fixed oracle's
complete default tables/configuration. Upstream credits the configuration to
Dany Castillo's MIT-licensed tailwind-merge. `LICENSE-TAILWIND-MERGE` preserves
the notice from `tailwind-merge@3.7.0`'s `package/LICENSE.md`, Copyright 2021 Dany
Castillo. Only its license was extracted; no tailwind-merge engine is included.
The source tarball was
`https://registry.npmjs.org/tailwind-merge/-/tailwind-merge-3.7.0.tgz`, SHA-256
`6b1add695cf419b29b82843cdcaaafe49157dc90d4d1772dcc0e7672da538c42`.

Reproduce/check the generated data from the repository root:

```sh
python3 crates/rustify-style/upstream/cn/generate.py --check
```

The script first verifies the locked development oracle, then generates the
Rust defaults from its JSON and extracts the emission template from the locked
upstream source. `--write` deliberately replaces generated files; neither the
production build nor the runtime invokes Python, Node or upstream TypeScript.

`unicode-emission.fixture.json` was generated by the same locked compiler for
the explicit two-emoji literal configuration it contains. It verifies factoring
a common high-surrogate prefix without replacing code units by U+FFFD.
