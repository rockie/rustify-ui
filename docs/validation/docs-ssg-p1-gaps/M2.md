## 真实 Safari 续验

本轮仍使用原四套固定production产物；[HTTP/指纹](m2/safari/preview-http-proof.json)确认loopback入口与原manifest一致。桌面实际Safari通过原生`safaridriver --mcp`控制；早期交互终端的长响应不完整，保留于[初轮日志](m2/safari/initial-interactive-session.json)，后续使用完整stdio日志并核对实际`location.href`、页面语义和截图，不以命令返回判导航完成。调用脚本保存在同一证据目录。

- 脚本开启：首页边界记录32项，两base×1280/375，唯一H1/id、标题未被页头遮挡、Same/跨页链接及空配置真实页脚返回均通过；raw正文为Same Automatic，Lire保留fr。完整站记录18项，阅读/页头/侧栏/前后页、跨页深浅色、普通与中文锚点、窄屏、真实404及返回已验证。
- 真实缩放/禁脚本：普通Safari的网页缩放弹窗实际从100%改到200%，标题高度39→77；两base阅读页与auto/explicit/raw/empty共10个状态的地址、唯一H1、锚点位于页头下方、页脚和文档宽度均通过。禁脚本通过Safari安全性开关1→0执行，两base及1280/640宽度共24条记录；主题/复制增强控件消失、H1/页脚与阅读内容保留，空配置页脚真实返回基路径首页。JavaScript已恢复0→1，页面缩放已恢复200%→100%。
- 减弱动态：[系统开关](m2/safari/motion-setting-on.json)0→1；普通窗口Web Inspector只读表达式实际显示reduce=true/scroll=auto，见[观察及限制](m2/safari/reduced-motion-observation.json)。自动化配置仍返回false/smooth，未将其当启用后的结果；初轮普通窗口的URL片段提取不完整；续轮在已核对指纹的localhost首页取得完整URL，见下方收口证据。macOS27入口按[Apple当前说明](https://support.apple.com/zh-cn/guide/mac-help/mchlc03f57a1/mac)位于无障碍的动态效果。
- 复制：LAN HTTP实际显示Copy failed并选中源码；同产物localhost显示Copied，`pbpaste`与原文逐字一致，37字符。
- 请求/console：真实404主文档为404，样式和脚本正常加载。Safari还自动请求了页面未声明的`/favicon.ico`，返回404；该探测与缺页导航分别记录。后续console的两条404日志对应两次缺页导航，没有观察到脚本异常；未声明的favicon探测不作为页面引用资源损坏。
- 截图：已实际查看宽屏首页/深色阅读页、窄屏阅读页及子路径raw/empty。原生full-page截图可能将sticky页头记录在滚动位置；200%使用实际缩放值与AX布局验证。系统截屏权限为false，未保留空白viewport截图作为200%证据。
- 环境：en0在192.168.123.44与192.168.16.131之间变化，绑定旧地址的入口随之失效。桌面改用loopback完成走查；四套LAN预览已绑定0.0.0.0，当前入口见[清单](m2/browser-checklist.md)，网络再变时替换地址即可，设备可达性仍待实测。
