						113 text One browser page can run several  instances , and each instance is a wasm instance: its own linear memory, its own host hooks, its own diagnostics ring, its own everything. Inside one instance are  scopes  - the mount points Leptos owns - and inside a scope are the DOM and, when the application turns on the SDK's  gpu  feature, the  GpuRegion s. The default build is DOM only and links no Makepad. Leptos owns the DOM and the application's reactive state; every  GpuRegion  owns a Makepad  Cx  that draws into a canvas the DOM laid out. The two never share widgets or state: the application projects state into regions as props and receives typed actions back.
					114 文本 A trap stops at the instance boundary. Everything in the instance it happened in is gone - every scope, every region, every task - and nothing outside it is touched, which is what lets an application be embedded on a page it does not own.

							361 text Two hosts, one contract.  Whatever an instance hands back to the browser - a listener, a task, a timer, a size observer - goes through the hooks its loader handed to  rustify_runtime_boot : an abort signal,  defer ,  defer_after ,  observe_resize , the instance number and the protocol ( runtime::PROTOCOL ). A GPU build hands over the Makepad host, so the SDK and the regions share one; a DOM build gets one from  dom-runtime.js . Both loaders compare the wasm's protocol with their own before creating anything, the boot compares the hooks' again, and a mismatch is a  BuildContractMismatch  that releases what was created.  mount  refuses with  RuntimeNotStarted  until the runtime has started: a scope whose listeners nothing could end is worse than no scope.  Pace  is the Makepad integration's type with  gpu  and an identical SDK enum without it.
