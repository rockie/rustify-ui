字体偏差：原 LXGW WenKai 的 format 4 长度溢出；删除该可选损坏记录，保留原 format 12/6，字形、度量及布局表原字节不变，重算校验和。依 OFL 将修改版命名为 Rustify WenKai，资源路径保留；新输出 SHA256 为 `1d4b2f008ac7e02780c19801d4b04dd4538e40215943cc8ad374dba8ec2278c0`。来源与修复脚本锁在 sources.lock.json，新字体 notice 保留原版权/OFL。格式选择依据 [OpenType cmap 规范](https://learn.microsoft.com/en-us/typography/opentype/spec/cmap#format-12-segmented-coverage)。实际 name 表也纠正 notice 中 LXGW 年份及 Noto Sans 权利人摘要；原 Makepad 导入 fingerprint 未改写。

本机完整 native Draw crate 受既有移除后端/Apple ABI 问题限制；本里程碑以真实 CPU 文本模块和真实 Chrome GPU 为相关检查，未宣称 native 后端可用。一次误用直接 Cargo harness 命令未带字体根环境导致找不到文件，按既有 run.sh 重跑全 34 项通过。整仓 fork 标准检查归 M6。

浏览器先暴露旧脚本构造未注册的 board、canvas 缺 class 尺寸及长 canvas 被滚动祖先裁剪；前两项修复实现，第三项在样本验收中使用足够高的真实视口。M4 编辑、M5 交换与存储、M6 全站验收仍待完成。
