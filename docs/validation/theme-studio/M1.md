## 交付

`ThemeDocument`/双模式/完整 49 token 作者字符串、稀疏 `ThemeValuePatch`、统一 `resolve`/`ResolvedTheme` 已从 SDK 导出。支持有限 CSS 颜色与 alpha、OKLCH→sRGB 裁剪、名称/schema/数字边界、rem 像素换算、字体栈安全解析与回退诊断、圆角档位、结构化阴影。旧 API 字段、Copy 与 23 个 CSS property 契约保留，仅提供单向转换。

[格式说明](../../themes.md)和[JSON schema](../../theme-document.schema.json)已落盘；schema 的必填 token 与 Rust 常量有一致性测试。字段语法及与上下文相关的数值边界仍以 Rust resolver 为准，不能仅凭 schema 通过接受主题。

固化 42 个参考预设、实际输入副本、Apache-2.0 许可证及内容 SHA256；[来源记录](../../../examples/theme-studio/vendor/tweakcn/provenance.json)记载全 keys、真实合并规则、10 项公共字段模式差异。新站 Rust preset loader 补入五项 Rustify 扩展，包含两个 Rustify 预设，全部 44×2 模式可解析。构建输入不依赖 `ref/`。

## 实施选择与边界

字距 author 值额外接受实际预设的 `0.5px`、`0rem`、`normal`，运行态统一 em，已同步计划 §3.1。参考公共字段浅深色差异保留，resolver 返回诊断；本阶段不执行编辑同步。

为直接运行预设纯 Rust 测试，提前注册新 example/workspace 成员；页面、build/project 注册其余部分仍归 M2。默认 resolve context 没有已验证字体目录，不伪称 sans/serif/mono 两端已呈现；M3 负责资源与真实绘制。

旧基线无 revision 标记的 draw 确认，GL 时间只表示 CPU 提交，不能当显示器延迟。旧 ColorField 不修改 GPU 主题。旧暗色页部分正文仍继承深字，另有 favicon 404 和 UnsupportedCapability 诊断，均原样记录；本阶段不宣称全站无错误或暗色可访问性通过。

M2 下一步：实现 ThemeScope/ThemeBoundary 与 overlay 响应式投影、完整 CSS token 和 opt-in 映射，组装新站最小 DOM 样本及 catalog 同产物旧/新 fixture，通过 V2。V3–V8 未验收。
