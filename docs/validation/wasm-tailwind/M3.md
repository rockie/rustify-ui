# M3 · 第一条动态 DOM 编译路径

计划：[WASM-TAILWIND](../../plan/WASM-TAILWIND.md) · 更新：2026-10-04T18:26:02+11:00

状态：已完成 M3 的最小动态 DOM 闭环。此处不声明全量 Tailwind、GPU 或整期交付；M4–M7 及 M2 尚有明确缺口。验证工作树仍为 dirty@`fb288564caed23f79e34bd8ac28dae2f6f44bfeb`，未提交。

`rustify-ui` 的可选 `utility` feature 仅依赖 cn/protocol。`UtilityScope` 接收 ScopeRoots 与调用方正数 limits，通过独立 module Worker 初始化 Rust CompilerSession。`ensure_classes` 合并同轮请求并保留每个完成通知，排队与在途工作共享预算；先检查预算再克隆候选。编译生成结构化 AST、CSS 与 GPU program 数据，JS 只调用 Web API、校验传输身份、操作 CSSOM 和清理资源。当前 GPU program 数据不等于 GPU 呈现支持。

安装路径为 prepare → staged CSSStyleSheet → 固定位置 adoption → 主线程快照 → ack。CSSOM 失败 nack 且保留旧快照；ack 丢失后以已安装快照恢复。retry 创建新 epoch 并重放已安装候选，期间保留原样式。MutationObserver 读取 classList 与新增子树，排除其他 owner 的节点；不调用 extractor。dispose 与实例 abort 通过 JS bound cleanup 终止 Worker、断开 observer、清理 stylesheet/owner；trap 清理不依赖 Rust Drop。

`build-web` 检测 WASM 的 utility protocol export 才生成独立 compiler bundle，并按当前 bindgen imports 复制 SDK JS snippet。独立 bundle manifest 记录 protocol/build identity/资源 SHA；root 与 subpath 共享相同资源闭包。此次发现的 snippet 漏复制已通过实际浏览器 RED 和构建回归修复。
