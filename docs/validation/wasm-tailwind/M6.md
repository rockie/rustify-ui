来源：[WASM-TAILWIND.code-review.r3.md](../../plan/WASM-TAILWIND.code-review.r3.md)（R3 修复效果复审，sha256 `61515317…7ae2`；所审 dirty@`53652fc`，输入指纹 `6e4ef3de…13c8f`，scope.rs `7a8bcaf6…a0d4`）。R3 判 R2 / F-04 部分解决，新增 F-05、F-06、F-07；R1 各项与 R2 的其余结论不变（F-03 见 [M7](M7.md#评审修复代码评审-r1)）。修复目标为 dirty@`53652fc` 当前工作树，未提交（计划无提交约定）；修后 scope.rs `d13fd89a…eb14e`。修改路径：`crates/rustify-style/src/scope.rs`、`tests/browser/utility-runtime.spec.ts`、计划 §5.4 第 6 步（补一句失败语义）。修后产物：main `9926118ec160f77a`（未变）、compiler-only Worker `85684fa8…fcc1f7`，root 与 `/tools/utility-lab/` 相同。

四项同根：R2 的实现对每个 token 只看局部（变量按全局角色升级、`var()` 不占位、函数一律当 easing、数值不占位），猜测其所属子属性。本次改为在 var() 代换后判定：

- 每个 `var()` 展开为该变量在样式表中的每条声明及 fallback；未声明且无 fallback 的变量视为未知值。shorthand 内用 64 种层状态（easing/iteration/direction/fill/play-state/name 六个槽位）的集合沿 token 推进，逗号分层，使声明无效的状态出集。
- 关键帧同名词只在集合内所有有效状态下都是名称时才改名。
- `steps()`/`cubic-bezier()`/`linear()` 占 easing 位。数学函数按结果的时间量纲判定：数值占 iteration，时间不占位，含 `var()` 时两种都算。无单位数值占 iteration。
- 一个变量在不同用途下需要不同改写时（timing 位、`animation-name` 列表、动画外的普通引用），首个用途（文档顺序）的改写留在公开声明，其余版本以 `--rustify-<owner>-k<n>-<原名>` 写在每条原声明之后（同选择器、同条件、同 `!important`，因此级联一致）。内部 `@property` 注册同步复制。只有存在冲突的变量才会产生副本。
- 归属取决于级联而无法静态确定时（同一变量在不同规则中给出使该词归属不同的值，或未知值之后紧跟关键字同名的关键帧），返回 `UnsupportedFeature`，配置事务按既有路径 nack 并保留旧 revision，不再静默产出失效动画。
- 展开上下文数受 `CONTEXTS` = 4096 约束，变量链深度受 `ast_depth` 约束。

## 配置事务、已提交 cn epoch 与 flush

`UtilityScope::replace_config(config, cn)` 先合并登记的 raw 片段，保留 callback 在主 realm；事务持有预合并结果，提交不重复调用 callback。新 epoch supersede 旧队列/执行中请求，同 epoch 新增类保留完成凭证。Worker `CompilerSession.replace_config` 暂存独立 compiler；旧 session 到 ack 前不变，nack 丢弃新准备。SDK 用最后安装候选、当前 scope DOM classes 和新 raw 输出重建，排除嵌套 owner；安装成功后同任务发布 report/programs、配置和 cn epoch。同步安装后校验失败可回滚 sheet。注册 raw 在等待期改变时拒绝该次准备，保留旧配置。

ack 丢失后不回退已安装状态；`configuration()` 返回成功安装配置，显式 retry 重放该配置/候选并同步 cn epoch。`flush()` 是 FIFO barrier，已有安装时返回 snapshot，无额外 Worker 编译；未安装时初始化空输入。配置回调、CSS 配置及安装失败均保持旧 class/CSS/programs。DOM/GPU 新颜色 #abcdef 的实际像素及旧结果保留已验证；GPU 由调用方在安全 props 阶段消费已安装 report，等待 drawn revision。
