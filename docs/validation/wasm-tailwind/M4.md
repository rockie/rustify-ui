## 前轮捕获顺序 variant 与原 body 数组

caller body作为opaque slot进入已有variant kernel，不先降低并重建整个body。生成树只序列化一次，然后接回原数组；自定义slot替换保留fresh模板数组。body内的property/keyframes在同一Current实际walk中改成at-root，保留原receiver及原children。自定义模板只在实际clone时从Current读取所选body，复用既有fresh cloner与实例化；没有按节点clone整个Current或全局刷新所有模板。领域读取仍用借用Current的typed适配，最终函数阶段仍是Edits，这不证明完整单次lowering交接。

## 前轮公开 API 与 UTF-16 验证

以下为前轮证据及实现背景；当前 family 链路与新版 module 的结果以上节为准。


`compiler-api` feature 导出 CssCompiler、AstCompiler 与 DesignSystem。构造器接收原始 JS 字符串与 JSON 配置；CSS、SourceAsset.content、Stylesheet.content 和 stylesheet AST 全部文本字段使用 Text。CSS parser 直接扫描 UTF-16 units，Syntax.offset、Source spans 与 map 坐标不做二次换算。AST、ValueNode、CompileError 使用 direct typed JSON 解码，避免 tagged enum 的 Content 中间缓冲拒绝孤立 surrogate。scalar convenience 入口转入同一 parser/decoder；candidate 与部分公开元数据仍有显式 fallible 标量边界。

Value AST 的 Word/Separator/Function.name、Declaration.property/value、Rule.selector、AtRule.name/params、Comment.value 与 Context.base/source_base 已统一 Text；函数替换、scope 重写、emitter、clone、去重与声明 identity/provenance 使用同一树。Theme 使用一个 `BTreeMap<Text, ThemeToken>` 和一个 `Vec<Text>` 插入顺序，raw/prepared 值、依赖和 used-variable 集同样为 Text。部分 family 消费者仍将 opaque 文本转为 scalar；FamilyFailure 区分候选诊断与 CompileError，不能将资源错误吞成无结果。GPU 遇到非标量声明保留 DOM AST 并明确标 Unsupported；完整 GPU Text 模型归 M5。

公开 `theme_entries()` 现在返回 typed ThemeEntry，保留 Text key/value、options 和 optional SourceLocation；不再通过 serde_json::Value staging。WASM `themeEntries()` 重建原始 units，src 为共享 Source 对象与起止 unit span 的 tuple，无来源时保留 own property `src: undefined`。Source 缓存按 Arc 身份关联，并持有 Arc 防止地址复用；同一来源跨 token 与重复调用共享 JS 对象。首次 snapshot、JS 数组/文本、来源对象和临时构造费用在 clone/crossing 前检查，全部成功后发布缓存，超限可恢复。这是保守逻辑预算，未完成 allocator 测量或全范围 NFR-1。

DesignSystem 加载不保留未使用的 root mapped AST，但 `options.from` 是否存在仍决定 imported Source tracking。实际上游差分确认 `from: ""` 会追踪导入来源，却不会生成打印 destination；普通 CSS compile 保留该区别。[Source map 反例](utf16-public-api-gate-source-map-first.log)修正后，undefined/empty/nonempty from × scalar/lone imported content × missing/empty/nonempty resolved path 的 18 例、36 maps 与 24 Source 身份检查通过。typed ThemeEntry 的所有 111 条冻结观测从公开入口保留原始 key/value units，而非 direct-AST 子集。

`track_used_variables_text` 与 WASM `trackUsedVariables` 按原始 units 解析 CSS 变量；保留上游 prefix slice 与 legacy key unescape 语义。escaped、literal-backslash、replacement-character、lone-unit、重复追踪、prefix 与非法 code-point 组的 20 项生产上游比较通过；非法 key 仍抛 RangeError，先解码后查是否存在，不通过查不到 token 绕过错误。

Compiler render 明确区分 Setup 与 Build。Setup 不收集普通 CSS/keyframe 的使用变量，相关 unescape 错误留到 Build；Features.NONE 直接保留原始 CSS，不提前运行使用变量优化。legacy unescape 在错误发生处返回 typed `CompileError::RangeError { message: Text }`；function failure 中 Syntax/RangeError 按上游成为无效 candidate，其余资源/迁移错误传播。WASM 公开 facade 抛真实 Error/RangeError，message 使用原始 Text units，typed 错误 envelope 放入非枚举 `cause`；协议错误为 TypeError，调用方 getter/Proxy 异常继续原样传播。CompilerSession 的 JSON wire envelope 保持原协议。

当前 61 条冻结错误逐项检查 compile/build 阶段、真实 Error/RangeError 原型以及 name/message units：59 compile、2 build，其中 6 RangeError，全部通过。另 3 项失败后重试/来源保留/Features.NONE passthrough 与 1 项协议 TypeError 通过。native 测试覆盖 deferred variable/keyframe/function-output 错误、失败后的 report/cache 保留、dependency 区别和字段重排 typed JSON。此前标量 legacy harness 错把全部错误当 constructor Syntax；其冻结生成器同时捕获构造与 build，两处 harness 已按原始阶段改正，未修改预期。

DesignSystem 的冻结十二方法有限值比较、完整 class list 和 variant selector probes 保持通过：class order 为 BigInt，variant order 为 Map，缓存 key 对象身份保留。selector 回调由 JS 持有 Rc 状态，wrapper 释放后仍可调用，getter 失败后借用释放。完整 mutable theme/utilities/variants 对象、async loader callback、compileAst/shared 节点图与公开值树仍未完成，不能由这些有限检查推定全部兼容。


## Candidate Text 前置与失败状态修复

arbitrary value 合法性校验统一为一个 UTF-16 units 算法，Text 入口直接借用 units，scalar convenience 转入同一算法。孤立 surrogate 是 opaque 内容；不增加原文没有的 whitespace 或未闭合括号/引号拒绝。固定源码 `ref/tailwindcss/packages/tailwindcss/src/utils/is-valid-arbitrary.ts` 的 Uint8Array(256) 在 overflow 后不再弹栈：257 层后再给匹配 closer/semicolon 仍返回 true，旧 Vec 实现返回 false。[真实 native RED](utf16-candidate-validity-native-red.log)后，五项测试通过，覆盖全部 65,536 units、标量入口等价、opaque quote/escape/whitespace 与 255/256/257/258 深度。[独立原文比较](utf16-candidate-validity-upstream.log)核对 source digest 并执行 260,163 项 Node 判定；完整 candidate payload 仍待迁移。

动画名集合现为 Text，按固定 ast.ts 的 ECMAScript whitespace/comma 切分。此前 to_utf8().ok() 会遗漏 lone keyframe，char::is_whitespace 则将 FEFF/U+0085 的资格判断反过来。[native RED](utf16-animation-native-red.log)与[旧 WASM RED](utf16-animation-wasm-red.log)后，两项 native 测试与[实际 WASM](utf16-prerequisites-animations-wasm.log)通过：23 authored 输入 × initial/add/repeat build = 69 exact CSS/69 maps，包含 direct/theme-variable usage、lone/replacement 区分和标量对照。未修改冻结预期。
