# P2 M8 report: acceptance and hand-over

Date: 2026-09-10. Machine: macOS (Darwin 25.6.0), Apple Silicon, rustc 1.97.0-nightly (2026-05-19), Node 26.1.0, Playwright 1.63.0 (bundled Chromium, SwiftShader WebGL), Tailwind CSS 4.1.13.

## Status

The automated half of the acceptance is delivered and reported. The manual half is not: four records need a person with a screen reader, an input method, a reference rendering and a browser at 200% and 400%, and none of them is in. `cargo xtask verify --suite p2` lists them as missing rather than reporting a pass, which is the whole reason that command exists.

**P2 cannot be called complete.** What it can be called is 8/8 on everything that does not need a person, with the four that do named.

| browser × 5 | Every Playwright project |

## The one long-running failure

`m8-endurance`'s memory tail assertion fails and predates P2 - established in M2 by building the pre-P2 commit in a `git worktree` and re-running the same assertion, which failed there with a larger margin (851,968 bytes against 786,432, on a threshold of about 420 KB). This run measured the same 851,968 bytes. The behavioural half of that test passes: everything sent is received, nothing refused, no errors.

It is reported as a known limitation, not as a P2 regression.
