## 交付

- **库 `rustify-docs`**（`crates/rustify-docs/`，只开 Leptos/SDK/components 的 `ssr`）：
  - `markdown`：pulldown-cmark 偏移事件 + 自有 writer（不用 `push_html`）。GFM 表格/任务/脚注/删除线/五种 alert，`{#id}` 之外的标题属性报错，表格对齐写 `text-left/center/right` 类，代码块按行包裹、`title`/`linenos`/`highlight` 解析与越界诊断、`<template>` 存原文供复制，外链 `rel="noopener"`；链接、图片、原始 HTML 与代码块带文件偏移交给 M3 的内容图。
  - `slug`：与 GitHub 一致的标题 id（NFKC、小写、保留各文字与 `-`/`_`、每个空白一个 `-`、不折叠），空结果 `section`，显式 id 先占位，自动 id 重复加 `-1/-2`。
  - `highlight`：syntect 5.3.0（纯 Rust fancy-regex）+ two-face 0.5.2 预编译语法；11 种语言含别名；每行闭合并在下一行重开作用域，类名 `hl-` 前缀（同 `ClassStyle::SpacedPrefixed`），按线程缓存作用域类名以避开 syntect 全局锁；浅/深配色单独成 CSS，不写 `style`。
  - `style`：rustify-style 原生编译，虚拟输入为 Tailwind 4.1.13 theme/preflight/utilities、去掉 `@source` 并换成文档暗色变体的 SDK 层、`docs.css`（components 层）；token 由 `rustify_ui::Theme` 生成并按 §6 换主色，按钮前景按 D11 取黑/白；Lightning CSS 按 Tailwind v4 的浏览器下限降级并压缩。Limits：输入/资源 1 MiB、候选 50 000、AST 深 128、CSS/队列 8 MiB、缓存 128 MiB。
  - `classes`：只读 `class` 属性（跳过注释、`script`/`style`/`template` 内容和 `hl-` 类）收集候选。
  - `shell`：Leptos 宿主渲染完整页面（`data-rustify-scope`、`data-theme="system"`、meta CSP、外部 head 脚本、侧栏/目录用原生 `<details>`、上一页下一页、`#rd-status` 朗读区）；渲染后去掉 `<!>` 水合标记再拼入正文，作者内容不经清理。
  - `generation`：片段缓存键含 writer/语法/解析选项版本、界面语言、文件偏移与正文；`available_parallelism` 有界并行，每页独立 Owner；样式表/脚本按内容指纹命名，整代在内存提交。
  - 框架资源：`assets/mode.js`（head 同步读按 base 隔离的存储键）、`assets/site.js`（模式切换、复制、目录高亮、侧栏定位的首版）、`assets/docs.css`、vendored Tailwind CSS（`sources.lock.json` 新登记 `tailwind-docs-inputs`）。
- **CLI `rustify-docs-cli`**（bin `rustify-docs`，独立版本 0.1.0）：`--version`、`--help`（写明只承诺 macOS）、`--build-info`（报告 panic 策略与语法版本）、隐藏的 `__panic-probe`；五个内容命令在后续里程碑交付，当前明确拒绝。
- **组件**：`Button` 在 `ssr` 下把 `disabled` 写成 HTML 属性（CSR 构建不变），新增宿主渲染测试。

## 偏差与决定

- **B 无图片**：12 份指南实际 0 张图片（`workspace.md` 中唯一的 `![` 在代码块内），B 按分布同样无内容图片；N2/AC-1 的静态资源保存用站点 logo（`static/logo.svg`）。
- **侧栏条目不用 `Link` 组件**：每页数百条，每条重复 `Link` 的类表并在渲染时做类合并，首轮 500 页 HTML 79 MB、热配置重渲 709 ms；改为裸链接 + `.rd-nav` 规则后 26 MB、33 ms。页头站名仍用 `Link`。
- **深色按钮前景**：按 D11 取黑/白中对比较高者（`#000000`），计划 §6 原写 `#0c111d`，已就地修订。
- **URL 转义自写**：pulldown-cmark 0.13 不再导出 `escape_href`，`escape::escape_url_into` 自行百分号编码不可直出的字节并保留已有 `%xx`。
- **许可**：CLI 图 236 包，新增 46 个；Lightning CSS 系（lightningcss、parcel_selectors、cssparser*、dtoa-short）为 MPL-2.0（文件级 copyleft，作为未修改的 crates.io 依赖使用），其余均为 MIT/Apache/Zlib/Unicode/BSL 等宽松许可；清单 [m2/licenses.json](m2/licenses.json)。`cargo metadata` 的 resolve 是全工作区特性合并后的图（会含 GPU 成员带进来的 makepad 包），单包结论以 `cargo tree -p` 为准。
- **mbx 托管 target 会被整体回收**：会话中 `target/`（mbx 符号链接）被重建，M1 时的示例产物不复存在；V-3 受影响判断因此在 `179c5ec` worktree 与当前树分别重建全部产物后逐字节对比，而不是与旧产物对比。
