rustify-docs 0.1.4
Build a documentation site from Markdown.

Usage: rustify-docs <command> [options]

Commands:
  new <dir> [--template content]   Create a site in a new or empty directory
  check [--external-links]         Report every problem in the site without writing anything
  build [--base <path>] [--out <dir>]
                                   Write the production site (default: build.out)
  preview [--dir <dir>] [--base <path>] [--port <n>] [--host <address>]
                                   Serve a production build as a static host would
  dev [--port <n>]                 Serve the site from memory and update open pages on save

Options:
  --config <path>        The site's rustify-docs.toml (default: ./rustify-docs.toml)
  --format text|json     How check and build report (json: one object on stdout)
  --deny-warnings        Fail on warnings as well as errors
  --version              Print the version
  --build-info           Print how this binary was built
  -h, --help             Print this help

check and build work offline; check changes no file, and requests the
site's links to other sites only with --external-links. preview listens on
127.0.0.1:4189 unless told otherwise (the next free port if that one is
taken; --port 0 lets the system choose). dev listens on 127.0.0.1 at
dev.port (default 4188; likewise the next free port if taken), shows drafts
and writes nothing. Exit status: 0 on success, 1
when the site has errors (or, with --deny-warnings, warnings) or a
command fails, 2 for a usage error.

Supported on macOS. Linux and Windows are not verified.
