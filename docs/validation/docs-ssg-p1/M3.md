## 交付

- **配置**（`config`）：`rustify-docs.toml` v1，未知键报错并定位；`schema_version` 必须为 1；目录规范化为工程相对路径，`build.out` 不得与内容/静态目录重叠或为根；`site.base` 规范为 `/` 或 `/a/b/`；`site.url` 须为绝对 http(s) 且路径等于 base；`[repo]`、`theme.primary {light,dark}`（#RRGGBB）、`theme.logo`（单值或浅深成对）、`nav.groups`（`dir` 或 `items` 二选一，`scope` 为路由前缀）、`nav.top/social`、`dev.port`（默认 4188）。
- **frontmatter**：`---` 分离并保留偏移，未闭合报错；serde_yaml_ng 读取，未知键报错，位置换算到文件。
- **原始 HTML 检查**（`html_check`，html5gum WHATWG 分词）：script/style/iframe/frame/object/embed/base/meta/link 元素、`on*` 属性、`style` 属性、`javascript:`/`vbscript:` URL（解实体、去空白/控制字符、不区分大小写）报错；资源须同源本地（图片允许 `data:`），srcset/poster/SVG `href` 均查；`img` 缺 `alt` 为警告；URL 属性的原始值区间作为槽位。
- **GFM 扩展自动链接**（`autolink`）：`www.`/`http(s)://`/邮箱，按 GFM 规则裁剪尾部标点、不配对 `)` 与实体；不在链接与代码内。
- **writer**（`markdown`，WRITER_VERSION 2）：链接/图片/原始 HTML 的 URL 记为片段 HTML 中的槽位，片段只依赖自身源文件与 include 文件；表格对齐为 `text-left/center/right` 类、无 `style`；五种 alert；代码分组 `<!-- rustify:code-group name="…" -->…<!-- rustify:end-code-group -->`（无脚本全部可读，标签栏 `hidden` 待脚本增强）；片段引用 `<!-- rustify:include path region lang title -->`（区间标记行排除、原字节保留）。
- **内容图**（`content`）：输入快照（不跟随出界符号链接、私有路径不发布）；路由冲突与 `/404/` 保留；页面语言；片段缓存键含 writer/语法/选项版本、界面语言、偏移、正文与引用文件内容；标题/多 H1/跳级/描述规则；`.md#锚点`、`/路由/`、目录、内容内文件、仓库文件（需 `[repo]`）解析与断链/断锚诊断；**首页 `actions[].link` 与 `nav.top/social` 走同一解析**（结果存 `Page.action_targets`、`Analysis.top/social`，错误定位到 frontmatter 或配置值）；草稿（生产排除且链接为错误，dev 降为警告）；图片/媒体须存在且同源；站点范围同名代码分组标签集一致；导航（目录按 `sidebar.order` 再按路径；`sidebar.group` 把页面移入同名配置组，未知组名报 `nav-unknown-group`，无配置组时按其另起一组；默认组同样按 order 排序；`items` 列表不被移动；缺页报错、未入导航警告）；logo 存在性；品牌色对比警告（D11）。诊断按文件/行/列/严重度/规则排序去重。
- **生成**（`generation`）：逐页填槽（页面路由加 base 与锚点、资源输出名、仓库 URL），静态目录文件按原路径发布，其他被引用文件按内容指纹进 `assets/files/`；渲染壳、收集候选、一次编译样式表。站点名链接改为 `LinkMatch::Exact`（此前在 base 下每页都带 `aria-current="page"`）。
- **CLI `check`**：`--config`、`--format text|json`、`--deny-warnings`；JSON 模式 stdout 仅一个对象（`schema_version/success/diagnostics/summary`）、stderr 为空；文本模式诊断与结论行在 stderr；有错（或拒绝警告时有警告）退出 1，用法错误 2；`--external-links` 明确拒绝（后续里程碑交付）。
- **语法参考**：[docs/docs-ssg.md](../../docs-ssg.md)（命令与 JSON 形状、工程布局、配置 v1、frontmatter、标题 id 规则及 `{#id}` 在 GitHub 上的差异、alert、链接解析表、图片、原始 HTML 规则、代码块选项与 11 语言标签、代码分组、include、草稿、诊断规则表）。其中“分组跨页同步”“dev 草稿显示”是 M5/M6 交付的行为，M9 定稿时复核措辞。
- **B 生成器 v2** 与性能组：B 经内容图分析为 0 错 0 警告，`docs-verify --group performance` 新增此项为必过检查。
