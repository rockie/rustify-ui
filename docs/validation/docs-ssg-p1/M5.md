## 交付（实现）

- **布局**：76rem 居中框；≥1280 侧栏 15rem / 正文测度 36rem / 目录 14rem；768–1279 目录折叠在正文上方；<768 单栏。宽屏侧栏与目录是普通 `<nav>`，窄屏才是原生 `<details>`，二者按宽度 `display:none` 互斥——WebKit 不把“关闭但被 CSS 显示”的 details 内容放进无障碍树（实测 aria 快照为空），故不再依赖 `::details-content`。
- **首页**（`layout: home`）：标题 H1、标语、actions（首个实心、其余描边，hover 向前景色混合保持对比度）、按条数决定列数的特性列表（发丝线分隔，非卡片）、其后页面 Markdown（开头 `# 标题` 并入 hero，不重复 H1）。
- **页头**：普通链接的站点名（仅首页 `aria-current`）、按图片宽高比写入 width/height 的 logo（浅深成对时 CSS 切换）、带绘制图标的三段模式切换（窄屏仅图标、文字对辅助技术保留）。
- **正文**：GitHub alert 改为浅色调底 + 发丝边框 + 绘制图标（不再用粗侧边线与 Unicode 字符）；脚注回链改为绘制图标；代码块复制按钮带图标与 Copied/Copy failed 状态；任务框按调色板绘制（勾的颜色每模式取品牌按钮前景）；统一面板圆角 `--rd-radius`；代码横向溢出时边缘渐隐提示与细滚动条；表格等宽数字；`::selection`、滚动条、焦点（3px 不透明 + 2px 间隔）主题化；锚点目标留出页头高度。
- **图片尺寸**：新 `imagesize`（PNG/GIF/JPEG/WebP/SVG 头部）；正文图片缺尺寸时写入文件固有 width/height（仅绝对尺寸，SVG 仅 viewBox 时保持随栏缩放），避免加载位移。
- **site.js**：模式切换跨标签页同步；复制在非安全上下文或被拒时显示失败、朗读并选中代码供手动复制；代码分组标签（roving tabindex、方向键/Home/End、同名分组同页同步、按 base 记忆并跨页保持、storage 事件同步）、分组共用一个复制按钮；滚动目录（首节/末节规则）；窄屏面板点链接或 Esc 关闭并回到开关；侧栏滚到当前项。
- **其他**：`WRITER_VERSION` 3；`recursion_limit = 256`（Leptos 视图类型擦除）；新增 `copy_failed_short` 文案；`rustify-components` 在 docs 库中已无 Rust 调用（仍编译其 CSS 层、使用 `rustify_ui::Theme`），依赖保留给 P2。
