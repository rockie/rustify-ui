## 实现接口与恢复线索

- `rendering::build` 将冷态 name/field 检查回调交给 `rust_site::prepare_checked`，预检失败仍检查两个编译目标；Child URLs 在 helper 前由现有 article 解析；组件、演示、原文和资源进入 generation::Extensions。
- `Prepared` 保留完整原始输入、不可变 helper/资源组、timings 与来源切片；render 前后、CSS 生成后、publish 前再次 validate_current。只有唯一错误为 rust-generation-changed 且 config 未变才有限重跑一次。
- 共用 site! grammar 是计划示例的 Rust identifiers / typed fields / adapter，以及直接 `crate::module::function` demo source path；CLI不猜 self/import alias 所在词法模块，不能定位时给直接源路径建议。
- 内置 props 冻结为 Tabs.tabs[{label,content}]、CardGrid.cards[{title,link,description}]/columns 默认2且1–3、Steps.items[{title,description}]。这些 strings 为转义的纯文本，额外 children 为同一 Markdown 管线；源码/复制仍用现有代码组，CR 以实体保留。
- P1 shell 已在清理自身 `<!>` 后事后拼接 article，本期复用该保护；M3 slots 仍须同样保护，不能在清理区直接插入岛。
