## 必要澄清与修复依据

V-2 的完整树比较在接管返回时对照 SSR，允许的浏览器延迟工作稳定后对照独立 CSR。规范化在真实 DOM clone 上删除已核实的框架占位 comment 和运行期标记、规范属性顺序；不删元素、文字、原生值、ID/ARIA 或几何。所有原始节点身份另行检查，不依赖规范化。Toaster 的延迟空 portal 是稳定后比较的原因；把 textarea 序列化再解析会把 comment 拼成 RCDATA 文本，因此 verifier 改为先 clone/delete COMMENT，再序列化，而未修改产品文本值。[初次探测](m1/hydration-probe.json)及[首轮失败](m1/browser-r1.json)保留；不能把探针解析伪影称为产品 bug。

旧目录的颜色失败只在共享页面 reset 后复现。[实际 DOM/CSSOM 探测](m1/legacy-geometry-reset-probe.json)显示 stylesheet 数从 1 到 0，重开后仍为 0，无新规则/无 pageerror；[独立回归红测](m1/geometry-reset-red.log)确认预览透明。根因是 Owner cleanup 保留 context 却销毁它的 StoredValue；复用前检查存活是修复点，未迁移 SDK marker 所有权。73 项整组重跑是最终绿证据，单独新页面通过不作为修复证据。
