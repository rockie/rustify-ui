WebGPU 另作对照

03 / 使用与恢复

一次操作有清楚的结束点，故障有明确的数据边界

拖动结束，才记一次历史

按下指针开始操作，抬起提交。Escape、指针取消或活动手势失焦会恢复原文档。覆盖画布画出九个手柄、选择框、吸附参考线和标尺；界面尺寸由框架同步。

编辑文字，交给原生输入框

光标、选择、组合输入和文本内系统撤销由浏览器处理。Escape、Ctrl/⌘Enter 或失焦提交；开始其他命令或切页前同步结束会话。外部文字变化会丢弃旧草稿与待提交历史，保留外部值。

写入成功，才显示已保存

文档变更后防抖 500 ms，再串行写入。尚未提交的拖拽、字段或文字操作不进入恢复副本。IndexedDB 打开或读取失败时回退到 localStorage；写入失败显示红色状态并提示导出。

画布恢复与整个实例重启，保留的数据不同。

GPU 初始化失败或 WebGL 上下文丢失时，文档仍在应用中，框架重建区域后重新绘图。Wasm 是浏览器执行 Rust 编译结果的运行环境；Wasm trap 会终止整个实例，未保存编辑会丢失。实例重启只恢复已保存副本，未保存编辑不能跨实例保留。原文记录的恢复验证中，文档和相机完全相同，区域数从 0→1，颜色与绘制恢复。

关闭后，旧任务不能继续写入

框架的终止信号配合应用接线，取消计时器和待执行动画帧，终止事务，关闭数据库并移除字体。已排入的框架内部 Promise 微任务并未统一取消；应用在异步结果写回前另查实例是否存活。

字体随文档替换和撤销/重做同步。旧字体加载结果失效，已删除字族移除；原生关闭回调不再调用已终止的 Wasm。

取消与拒绝都要如实反馈

文件选择取消或校验失败不会提交编辑。系统剪贴板写入成功才提示已复制；拒绝时明确提示只能在 Vellum 内粘贴。粘贴数据先校验，旧载荷保持兼容，可选字体字段随载荷保存。

导入文档形成一笔可撤销替换，图片与字体随历史恢复。PNG 导出使用独立图片缓存，演示预览用请求代次拦住晚到结果，避免旧画面覆盖当前状态。

对象限制行为
文档 / 图片 / 字体导入80 MiB / 25 MiB / 15 MiB应用校验大小和格式，拒绝不改变文档。
图片解码与放置超过 64 百万像素拒绝；放置后最长边不超过 800 逻辑像素文档中的图片资产保留原始分辨率。
PNG 输出64 百万像素；每边 16,384 像素先等待图片解码，屏幕与导出复用绘图规则。
系统拼音输入法与物理触控板尚未人工验证。

浏览器组合输入和双指事件已自动化覆盖，有头浏览器也完成了界面操作与截图检查。这些证据不能替代真人操作系统候选窗或真实触控板。两项未测记录保留在最终验收报告中。

04 / 实测与取舍

合批减少绘制，分帧缩放先显示再细化

以下是本机浏览器样本。p95 表示把样本从快到慢排序后的第 95 百分位值。CPU 时间是处理器执行工作的耗时；呈现时间从输入事件到框架观察到绘制帧，不是物理显示器延迟。

最终性能记录

6.3 ms5,000 形状编辑 CPU p95
34.8 ms30 次平移呈现 p95

连续 20 次编辑均产生画面，实际绘制次数为 1。平移未触发 50 ms 的方案重评条件。

冷缩放首次呈现 14.7–19.6 ms，完成细化 67.5–146.3 ms，耗用 2–5 帧。每批约 8 ms 后不再开始可延后的工作；单个 Canvas 操作不能中断，新节点无旧像素时仍同步生成。

资源计数有各自的口径

启动页包含 171 层、173 个绘图实例、144 次绘制、1 个 GPU 区域。框架 GPU 账本记录 1,450,576 字节，并非浏览器进程的全部显存。

CPU 像素缓存预算 64 MiB；GPU 只保留当前投影使用的纹理。20 级缩放重复三轮，GPU 字节序列相同，峰值 12,846,744 字节，未逐轮增长。这是资源检查结果，不是性能门限。

保留 4 个边缘像素差异，避免约 3 秒的缩放细化。

软件与 GPU 绘图在装饰线端点出现 4/120,000 像素差异，即 0.003333%。强制 GPU 绘图虽然消除这些差异，却让冷缩放细化从约 0.1 秒升至约 3 秒。应用最终设置 willReadFrequently=true，让浏览器使用适合频繁读取像素的软件路径；文字布局仍严格比较，像素继续遵守 2% 上限。

绘图、缩放与抗锯齿的阶段记录
  • 早期冷缩放一次生成 93–102 条文本像素，CPU 耗时 31.7–36.6 ms。分批后每批 2.8–9.5 ms，首帧 15–21.6 ms，经 2、4、6 次呈现完成细化；每批在 8 ms 后不再开始可延后的节点。以上为早期样本。
  • M3 的文字裁图在通道和阈值 24 下为零差异。六个大光栅累计触发 104 次淘汰，缓存留下 58,867,200 字节，低于 64 MiB。后续发现默认 Canvas 第 3 次读回会更换绘图后端，端点透明度由 127 变成 98/105。
  • 最终软件路径的 M7 回归为 7 项通过；缩放 0.49 时，细化 101.1 ms / 4 帧，仍有 4 个端点差异像素。m7-raster-probe.log 是诊断记录，m7-raster-fixed.log 是未采用的 GPU 方案性能记录，m7-canvas-raster.log 是采用软件读回后的记录。
  • 早期 30 次平移 p95 为 44.5 ms、最大 55.6 ms；方案重评条件是 p95>50 ms，未触发。M5 回归指针 13/13、场景 6/6；平移 p95 34.8 ms，5,000 形状编辑 CPU p95 6.2 ms，20 次编辑均呈现、绘制次数 1。最终编辑 CPU p95 为 6.3 ms。

实现中的正确性与安全边界
  • 文档校验跨页唯一 ID、同页父子关系、循环与深度，未知字段往返保留。serde_json 启用 float_roundtrip，修复三个 1 ULP 漂移值——ULP 是浮点数最小表示间隔。历史最多 80 步，图片/字体字符串以 Rc<str> 共享；运行时不加载原版 JavaScript。
  • 应用使用浏览器 Intl.Segmenter、locale 大小写转换、Path2D 与图片 cover 规则，保留字素、换行和字体回退。若换成另一种文本测量器，字形与换行可能改变。CPU 缓存淘汰和 GPU 纹理保留分开管理；撤销、文档恢复、字体变化必须清旧缓存，同键新像素也要更新纹理。
  • 本地字体 data URL 先解码为字节再交给 FontFace；严格 CSP 的 font-src 'self' 无需增加 data/blob 例外。文件仍携带原始字体 data URL，卸载移除该作用域的字体；恢复字体不会改写文档高度。
  • 图层树转义名称并通过 CSSOM 设置缩进，名称中的 HTML 不会成为标签。结构使用 Memo 去重、选择只更新 class/ARIA，避免替换 DOM 打断双击和原生拖拽。macOS Chromium 需先拖动 8 像素触发 dragstart，再按 Shift；先按 Shift 会抑制拖动，原版相同。测试在 drop 检查 Shift，并核对六项世界矩阵不变。
  • 受控字段保留聚焦草稿，负号、指数与空值不被刷新抢写；合法数字实时更新，失焦记一次历史。颜色支持三位和六位十六进制，非法值回退并提示。SDK 负责浮层焦点和背景禁用，应用补方向键、Home/End、Tab/Shift+Tab；toast 在覆盖层根显示，不占 Escape 栈。
  • 文字会话变换原点为 0 0，应用提供完整世界矩阵与相机变换，避免重复计算旋转边界框偏移。开始编辑时 GPU 跳过该文字层，结束后恢复。用 Enter 重开先取消默认换行；文字工具也取消会导致失焦的默认鼠标动作。
  • History::discard_pending 防止外部文字更新被旧草稿覆盖；诊断入口 __vellum.replaceTextExternally 不走普通编辑事务。组合输入过程中 Enter/Escape 不关闭会话，自动化覆盖不等于系统拼音人工走查。
  • 存储键保持 vellum-editor/documents/current，回退键为 vellum-document；选项分别存于 vellum-options 与 vellum-welcomed。普通卸载清理监听、数据库和待完成写入，旧任务代次失效。故障保存与 toast 延时使用 defer_after，事件绑定运行时终止信号。
  • 文件选择器曾在取消后残留 2 个监听；修复后选择或取消均回到 0，并且只回调一次。PNG 与演示先解码图片，SVG 复用文字测量；独立导出缓存和演示代次阻止旧文档结果污染当前画面。
  • ?nogpu 可重现无 GPU 状态，页面与文档命令继续运行。GpuRegion 重建后重新应用当前数据；Pace::Continuous("stats") 合并同类统计通知。框架账本的帧/字节计数与应用的实际绘制计数分工不同。
