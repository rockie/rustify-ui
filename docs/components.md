# Component catalogue

This reference describes the current source checkout. The nine published
Docs/DOM/style packages remain at 0.2.1 with the previous component API and
schema v1. New configured themes, layout/typography APIs and Colors are source
capabilities; this document does not announce a package release.

`crates/rustify-components/src/catalog.rs` is the fact source. Regenerate with
`mbx xtask catalog --write docs/components.md`; add `--check` to detect drift.
The existing `CATALOG` has 24 navigation categories for older applications.
It is separate from the public-entry and complete stable-reference inventories.

A listed component exposes its stated Rust contract. Same-name reference
mapping does not establish the full upstream API, generic asChild/Slot,
unstyled Primitives, accessibility certification or DOM/GPU visual parity.
Verification columns identify checks to rerun; dated outcomes remain in
[component validation record](plan/DOM-COMPONENTS-P1.records/M4.md) and the development plan.
Use the [migration guide](dom-components-migration.md) for API, theme and CSS
changes, and the [field matrix](validation/dom-components-p1/field-matrix.md)
for defaults and enum values.

## Source boundaries

The DOM implementation and its public typed structures live in
[components](../crates/rustify-components/src/). Browser-only root theme aliases
are in [theme.rs](../crates/rustify-components/src/theme.rs); the existing
[DOM theme core](../crates/rustify-dom/src/theme.rs) owns author documents,
resolution, scope projection and overlay inheritance.

Existing GPU controls live in [the GPU module](../crates/rustify-ui/src/gpu/).
GPU draws a declared subset and can report actions or anchor DOM layers;
it does not implement the new DOM layout/typography catalogue. A themed
ordinary Table remains unimplemented; the existing DOM DataTable is a distinct
virtualized interactive grid.

The stable reference names come from the fixed local snapshots recorded in
[the reference baseline](PRD-DOM-COMPONENTS.md#15-参考基线与适用口径).
`ref/` is reading material and is excluded from the workspace. Catalog generation
and checks use committed Rust facts, not those local directories. Required
Colors/theme data and notices are recorded in [sources.lock.json](../sources.lock.json).
