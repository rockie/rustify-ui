## 偏差与修正

布局检查发现普通 CSR 两个 Toast Provider 均生成 `rustify-toast-1`，且无 ssr_scope seed 时 Title/Description 无关联。普通 mount 不提供 seed，旧回退使用 Provider 内局部 Scheduler ID。新增无 seed 双 Provider host 复现先失败，再将仅无 seed 的 DOM ID 改为单调全局分配；有 seed 的 SSG/hydration 保持原路径。修正位于 [toast.rs](../../../crates/rustify-dom/src/toast.rs)，契约已补计划 §4。

通知浏览器首轮标题/描述断言已过，但测试误以可见 Dismiss 代替组件的无障碍名 `dismiss this message`，关闭定位超时；改正确名称后通过。共享页保留手动展开的 details；诊断测试结束恢复折叠，最终布局截图由新进程确认默认状态。
