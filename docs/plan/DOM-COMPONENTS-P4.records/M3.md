## 交付

[`primitives/menubar.rs`](../../../crates/rustify-components/src/primitives/menubar.rs) 将应用的 `Option<String>` 映射到各非模态菜单，提供 Trigger 单一停靠点、RTL 横向切换和 Content/子菜单转交。根菜单的整树外部关闭边界为整栏。打开期间的 window capture 指针监听先辨认本栏 Trigger，Content 取消这次外部关闭，避免 core document capture 先请求关闭旧菜单再请求新菜单；只在当前值属于本 Menu 时请求关闭，旧 Content 清理不会关闭新菜单。对应机制已回写计划 §5.3，未修改 core overlay。

[`primitives/toolbar.rs`](../../../crates/rustify-components/src/primitives/toolbar.rs) 提供按 DOM 顺序移动的工具栏、原生按钮/链接、垂直分隔、ToggleGroup 与 `item` 属性装饰器。方向键按 orientation/RTL，字段编辑键、已取消事件和修饰键保留；链接仍走普通 scope 导航。选择与受控请求复用 [`choice.rs`](../../../crates/rustify-components/src/primitives/choice.rs)；其 crate 内 roving 参数让工具栏内组不再自行处理方向键或设置 tabindex，独立 ToggleGroup 的既有策略保留。

Themes 两栏沿 [surface brief](../../../.impeccable/surfaces/crates-rustify-components-src-menubar-rs.md) 与 DESIGN.md：紧凑分组、语义 token、明确选中/打开与焦点、窄幅局部滚动，不新增 size/variant。两侧 `menus.rs` 使用相同 test id 的文件/编辑/视图、切换组、菜单嵌入、搜索字段及纵向工具栏；演示控制与请求结果收进 details。
