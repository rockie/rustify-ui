## 交付与必要修正

[`primitives/navigation_menu.rs`](../../../crates/rustify-components/src/primitives/navigation_menu.rs) 与 [`navigation_menu/browser.rs`](../../../crates/rustify-components/src/primitives/navigation_menu/browser.rs) 提供受控 Root/Sub、原生目的地链接、延迟/跳过窗口、行内 Content、Indicator/Viewport 测量变量。外部关闭尊重同 scope 浮层，指针与焦点合并请求；导航不作为 Layer。Sub 的 Trigger/Content 只能属于自己的 Item。Themes、结构 CSS 与两侧应用外壳已接线，沿 [surface brief](../../../.impeccable/surfaces/crates-rustify-components-src-navigation-menu-rs.md) 与 DESIGN.md。

[`menus.spec.ts`](../../../tests/dom-only/menus.spec.ts) 的 31 个用例覆盖两级菜单、接受/拒绝/取消、键盘、触控模拟、RTL、Menubar、Toolbar 字段、原生导航链接/几何、移除、清理、实例 trap 与 ARIA。两侧样本提供独立第二实例，空导出菜单、保留链接的加载提示、搜索字段错误及真实 Menubar 快捷键。hydration DeliveryParts 增加五族静态组合与接管操作，宿主编译通过；完整接管门禁留 V-12。

验收修正：

- Toolbar 当前项移除时沿 DOM 顺序选择下一可用项，只有工具栏原持有焦点时才恢复焦点；不改应用选择值。
- 显式菜单 `aria_label` 优先于默认 Trigger 名称；有显式名称时不输出覆盖它的 `aria-labelledby`。SSG 与两消费者验证。
- 菜单测试等待真实焦点恢复后再按下一键；字段 Home/End 保留浏览器默认，方向键实际移动光标。noopener 新标签通过 context page 事件观察。raw 样本置于 Feedback 前，保留既有页面末尾 Tab 顺序。
- Catalog 保留原菜单名称和循环导航意图；ContextMenu 断言按 Themes 偏移及真实碰撞边界。Studio 的主题更新避开外部 pointerdown 关闭；同字体字宽测试加载 GPU 实际使用的 Plex Text.ttf，而非编辑器的 Plex Regular。原 0.1px 阈值保留，未改 GPU。
- V-5 暴露 Toast 真实缺陷：keyed DOM 先移除，Owner cleanup 后读焦点已落到 body；Chromium 移除前还发无目标 focusout。[`toast.rs`](../../../crates/rustify-dom/src/toast.rs) Root 保留焦点归属，仅无目标失焦经实例托管任务清理，卸载沿既有回焦链；显式 blur 后不抢焦点。首次直接 bool 记录修正失败，最终定向复验通过。计划 §4 同步此真实调用路径与处理边界；不改排队、计时或 core overlay 契约。
- 示例字体、按钮与工具栏 border-box 对齐已修正；窄屏工具栏局部滚动，页面不横向溢出。六张开/关导航截图留于 P4，历史 P1/P2/P3 截图已恢复。
