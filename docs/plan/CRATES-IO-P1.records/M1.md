## 交付行为

- 新增 `crates/rustify-dom`：承载 `rustify-ui` 的全部非 GPU 模块、`theme/`、utility 的 DOM 部分（`cn`、`state`、`browser`）、`web/` 四个 DOM 资源文件与 `tests/ssr_scope.rs`。清单无任何 Makepad 依赖，feature 为 `csr`/`hydrate`/`ssr`/`utility` 加仅供宿主集成的 `external-host = []`。
- `rustify-ui` 变为门面：保留 `gpu/`、`region.rs`、`utility/gpu*`，以 `pub use rustify_dom::*` 加显式 `pub mod theme/diagnostics/utility` 遮蔽核心同名模块，因此 `rustify_ui::Theme` 就是 `rustify_dom::Theme`，类型身份唯一。
- `Pace` 成为核心唯一定义；`rustify-makepad` 改以 `default-features = false` 依赖核心并 `pub use rustify_dom::Pace`，删除自身 `mod pace`。
- runtime 的 DOM 宿主导出判据由 `not(gpu)` 改为 `not(external-host)`：门面的 `gpu` 启用 `rustify-dom/external-host`，核心自身仍导出该宿主，两者不会同时给同一实例造宿主。
- `gpu_font_family` 与 GPU 字体资源存在性测试随 Makepad `Cx` 一起留在门面 `theme.rs`；核心保留中立字体目录与 digest 元数据。
- components、rustify-docs、rustify-docs-cli 三个 manifest 改用 `rustify-ui = { package = "rustify-dom", path = "../rustify-dom" }`，保留既有 `rustify_ui::` 导入名而使 DOM 依赖图不含门面。components 移除仅作转发的 `gpu` feature。
- 新增不发布的 `tests/crates-io/compat` 独立 workspace 探针，以真实类型赋值、ActionSink 投递与三侧共享 `Pace` 验证互通。

## 偏差与实现决定

- CSS 候选源树从 4 棵增至 5 棵：除核心 `src` 与 `web` 外保留 `crates/rustify-ui/src`。首版只列核心树时 `candidates.json` 由 53965 字节缩到 46458 字节，说明门面的 region 与 GPU 半边含有候选类名；补回门面树后仅 +15/-1 行。
- `xtask/src/docs.rs` 的 snippet 前缀随资源归属改为 `rustify-dom-`（wasm-bindgen 以资源所属包名分目录）。
- `verify.yml` 的 SDK 矩阵按可构建性拆分：核心与 components 无 `gpu` 构建，只有门面包有。
