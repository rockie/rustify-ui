## 交付

- 核心增加 FontResolution::Packaged/Css（默认 Packaged）、安全 CSS 字体栈解析与通用族补足；Css 保留作者族名，不引用静态资源或隐式 CJK/emoji，局部 patch 保持策略。GPU 的两处 ResolvedFont 构造显式 Packaged。
- Docs 配置增加 theme.fonts，校验描述符、重复面、私有/输出/URL/越界路径和扩展名；字体纳入 snapshot、引用依赖和 dev 的文件/祖先追踪。
- CLI 读取项目本地字体，生成 SHA-256 路径、正确格式的 @font-face、weight/style/swap；主题与字体读取共同受 snapshot/真实目标校验。无 theme.document 也可独立注册，不自动换站点字体；未声明族给出可定位、可拒绝的系统回退警告。
- ThemeInput 增加带 serde 默认的字体策略；CLI 显式 Css，SSR/hydrate 共用 prepare_environment。两个 new 模板都写出单一 theme.example.json，真实 ThemeDocument 解析验证两模式各 49 token、三个字体槽为系统通用族。
- 有许可的小型 IBM Plex woff2/ttf 资源、notice 和固定来源置于 tests/docs-ssg/fixtures/fonts/ 及自包含 components fixture；删除 CLI assets/fonts 全部内嵌副本与旧 docs-static-fonts 登记。新 fixture 来源登记 10 文件，Makepad/Theme Studio 字体保持原位。
- custom.spec.ts/serve.sh 覆盖声明/系统回退场景，新增 dev-fonts.spec.ts 验证字体修改、删除时保留完整 generation、恢复。两个模板 README、包 README、Docs/主题作者指南和设计上下文同步字体迁移；旧 0.1.32 行为明确标为历史版本，公开默认安装入口留 M6。
