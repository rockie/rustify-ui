## 交付

- 同一个 Button/native handler 支持七变体、四档响应式尺寸、局部品牌/语义角色、半径、高对比、loading 与原生 type；IconButton 强制命名入口并复用行为。loading 保留名称与几何，禁止回调及原生提交，使用自身 NodeRef 重申 native disabled；unavailable 保留键盘请求语义。Link 保留原生导航/属性与路径匹配，增加完整排版和下划线参数。
- 七个布局入口 Box/Flex/Grid/Container/Section/Inset/Reset，完整 Layout/Margin/Padding/Gap；八个排版入口 Text/Heading/Blockquote/Code/Kbd/Em/Quote/Strong。元素语义与视觉大小分开，Reset 只装饰单个类型约束的原生元素。参数以 [矩阵](../../validation/dom-components-p1/field-matrix.md)与模块公开类型对应。
- `Responsive<T>` 的六断点与稀疏继承；扩展既有 GeometryStyles/CSSOM 管理器支持媒体规则、低权重 components 层、固定规则 shape 原地更新和生命周期释放。CSS 值共享 host/CSR 验证，拒绝声明/规则/外部资源注入；无效 prop 以 `diagnostics()` 定位，保留页面和默认样式，有效替换可恢复。
- 受控 ThemePanel 的六类配置、逐组两模式覆盖统计/重置请求与中英文说明；没有第二份文档/历史。公共 `theme` 入口复用 SDK 的 browser ThemeScope/Boundary，静态渲染沿用完整来源的 `provide_static_theme`。
- 缓存色板查询供组件显式选色复用；未选色使用有效语义 token，静态局部角色 reset 防止嵌套组件串色，legacy 深色通过同一 mode helper 适配。刻度读取共享快照，不重复 scaling。
- 迁移全部仓内旧 Button 枚举/尺寸调用；历史 cn oracle 改为验证捕获输入的合并行为。新皮肤统一导入 SDK，显式声明 layer 顺序；包内样式 API 与 Docs 的虚拟样式资产同步。新增 [迁移指南](../../dom-components-migration.md)。
