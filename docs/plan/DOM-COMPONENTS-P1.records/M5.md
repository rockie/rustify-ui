## 交付行为

- DOM 配置、来源与保存界面复用同一 EditorState；现有 GPU 只消费共享快照。六类配置、base 与 overrides 一起参与历史与 no-op；ThemePanel 显示两模式覆盖数量，逐组和逐 token 解除保留其它作者值。预览模式独立于文档 appearance；未编辑的原生 Draft 和零 HSL 不制造覆盖。
- 新键 `rustify-ui.theme-studio.v2`；完整验证旧库后仅恢复到内存，升级须 Review 和显式确认。取消持续禁止持久化；`rustify-ui.theme-studio.v1` 不覆盖，SHA-256 内容寻址备份写入后回读才提交 v2。重开仍能取回原备份，旧键被修改或移除都有通知。
- `write_queue.rs` 快照绑定 epoch/操作身份，命名动作保序，仅合并相邻未发出 autosave；旧确认不替换较新的 editor/history/checkpoint/模式/偏好。失败暂停并保留逐操作结果，重试/取消均显式。
- 原生 Web Locks 锁内重读、比较与写入；原生 AbortController 取消 dispose/fatal 的待锁操作。Clearing 门禁阻止新 autosave 复活已清库；清除失败不报成功，取消恢复原许可。无锁保留编辑和导出，命名操作明确拒绝。
- 冲突可见外部 revision/主题/库摘要及完整原文；缺键与空字符串严格区分。Load/Keep/Save copy 只授权所复核版本；第三次写要求重新决定，保留的命名动作不能隐式重放。
