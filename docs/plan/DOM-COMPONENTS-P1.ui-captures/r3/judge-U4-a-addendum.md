#### UI-51 · [P3] 升级 Review 对话框底部，放弃动作与次级动作同权，而且用的是蓝边蓝字，和壳层、callout 的灰描边按钮是两套样式（U4 · 视觉、交互 · 部分解决 · 可挽回 0.1）

- **位置**：
  - U4-upgrade-review-1440-light 底部 y712–743：「Upgrade and save current draft」是实心按钮。「Download original data」和「Cancel upgrade」都是蓝色描边：字色 #1570EF，边框是浅蓝（取到 #8AB7F7）。两者尺寸和样式完全相同。
  - 对照一（U4-upgrade-pending）：同一流程的 callout 里，「Download original data」（y446–477）是 #D0D5DD 边框、#475467 字色，「Cancel upgrade」（y501）已经降为文字按钮。
  - 对照二：页头 Import / Export 也是 #D0D5DD 边框、#475467 字色。
- **现状 → 期望**：
  - 现状：callout 里已经分出推荐、次级、放弃三级；到了对话框又回到两个同权的蓝边按钮。同一个「Download original data」在 callout 和对话框里样子不同，「Cancel upgrade」在两处的权重也不同。
  - 依据一：G3 写明「蓝色用于选中与焦点」，壳层边框用 #d0d5dd，次级文字用 #475467。所以次级按钮不该用蓝字蓝边。
  - 依据二：R2 UI-51 给出的修法是「其余统一壳层描边，放弃动作放末尾改文字按钮」。
- **修法**：
  - 对话框底部和 callout 用同一个按钮组件。
  - 「Download original data」改为壳层描边：白底、#D0D5DD 边框、#475467 字色。
  - 「Cancel upgrade」改为文字按钮，放在最后，用 ghost-offset 几何让标签与左侧内容对齐（同新-5）。
  - 实心的「Upgrade and save current draft」保持不变，作为对话框里唯一的实心按钮。
  - 如果导入、导出对话框也用这套蓝边次级样式，一并改，全仓只留一套次级描边样式。
- **可挽回分**：0.1（视觉 0.1）。
