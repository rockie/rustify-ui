## 3. 差距清单（未关闭）

#### UI-02 · [P3] EN/中文、Edit/Preview 段间仍画两条线，与 Light/Dark、DOM/GPU 的单线画法不一致（U1 · 视觉、细节 · 部分解决）

- **位置与采样**：
  - U1-default-1440-light，EN/中文行 y=85：x=250 为 #84CAFF，x=251 为 #D0D5DD，相邻两列各一条。
  - U1-zh-top-1440-light（中文选中），y=85：x=250 为 #D0D5DD，x=251 为 #84CAFF。
  - U1-edit-390-light，Edit/Preview 行 y=145：x=61 为 #84CAFF，x=62 为 #D0D5DD。
  - U1-preview-390-light，y=140：x=61 为 #D0D5DD，x=62 为 #84CAFF。
  - 对照组：同帧的 Light/Dark 接缝只有 x=993 一列 #84CAFF，无论哪段选中都如此（U1-top-1440-dark 中 y=16 同样是单列）；390 的 DOM / GPU / DOM + GPU 接缝也是单列（x=122、226）。
- **现状 → 期望**：同一壳层里有两种分段画法，选中段与相邻段之间出现 2px 双色线 → 期望全部分段控件统一画法。依据：G3「选中边框 #84caff」、壳层扁平；G4「选中的模式/渲染器按钮使用按下态」。
- **修法**：EN/中文与 Edit/Preview 直接复用 Light/Dark 所用的分段组件。如果要保留现有组件，就给非首段加 `margin-inline-start:-1px`，选中段加 `position:relative; z-index:1`，让选中段的 #84CAFF 边盖住邻段的 #D0D5DD。焦点段按 Light/Dark 现有的内收环处理，或在焦点时设 `z-index:2`。
- **可挽回**：0.10（视觉 0.05，细节 0.05）

#### 新-1 · [P3] 中文态预览诊断标题字重混排：汉字常规，数字与拉丁字符半粗（U1 · 视觉、细节 · 新）

- **位置**：U1-zh-top-1440-light、U1-zh-configured-1440-light，诊断条标题「▼ 2 组文字对比低于 4.5:1 · 作者颜色保持不变」，x≈357–622、y≈210–222。放大 3 倍可见：「2」「4.5:1」是半粗，「组文字对比低于」「作者颜色保持不变」是常规字重，看上去比前后的数字细、浅。
- **对照**：英文同一元素（U1-default-1440-light「1 text pair below 4.5:1 · author colors preserved」）整句都是半粗。中文壳层标签「预设」「外观」「预览模式」能正常加粗，所以问题只出在这个元素上。
- **现状 → 期望**：同一标题在中文态失去字重层级，标题与诊断行区分变弱 → 期望中英文同一元素的字重一致。依据：G6「新增配置/错误/迁移文案同步中英文」；G3 壳层字体与 label 600。
- **修法**：诊断条标题改用与壳层标签相同的字体栈和样式类：IBM Plex Sans 后接与壳层一致的 CJK 回退，例如 `"PingFang SC","Noto Sans SC"`。如果该元素设了 `font-synthesis: none` / `font-synthesis-weight: none`，或继承了预览作用域的作者字体，改为继承壳层设置。目标是 CJK 回退也能显示 600：回退字体要有 600 字面，或允许合成粗体。
- **可挽回**：0.10（视觉 0.05，细节 0.05）

&gt; 合计可挽回 0.20 = 10 − 9.8。

## 4. 建议（不扣分）

目标图和规范要点中找不到直接依据，或者扣分会和前几轮的尺度不一致，所以只作建议。

1. **两个实心蓝按钮同屏（本轮新出现）。**「Download current theme」由 r3 的描边次级按钮（x=25 列 y=313/344 为 #D4D8E0 边）改成实心 #1570EF（y=381–412）。在 1440、768、390 的未保存首屏，它都和顶栏「Save locally」同时出现，主次不分。G3 写的是「蓝色用于选中与焦点」，但前几轮从未就「Save locally」扣分，为保持尺度一致这次也不扣。建议只保留一个实心主按钮，下载出口用次级样式，或者放进存储状态行。
2. **存储状态块与顶栏胶囊重复，而且本轮变高了。** 未保存态是 14px 句子加实心按钮，已保存态是绿色卡片「Saved / Saved on this device」。1440 首屏的「Presets」从 r3 的 y=550 下移到 y=618。可以压成一行摘要加展开，让预设搜索更早出现（R3 已提）。
3. 1440 下两个 18px 标题字重不同：「Rustify Light」粗体，「Rustify Theme Studio」常规（R3 已提）。
4. 保存状态胶囊加前导标识，用形状区分未保存与已保存（R3 已提）。
5. 品牌色、中性色选项加色块（R3 已提）。
6. 加跳到预览工具栏的链接或 landmark。本轮从品牌色选择器到 Dark 要 Tab ×115（R3 为 114）。
7. 200% 导出对话框的标题行与关闭按钮吸顶。U1-zoom200-export-end 中标题已滚出视口（R3 已提）。
8. **帮助文字有两档字号。** 配置组帮助文字行距约 19.5px，即 13px × 1.5，例如「Generates this group's…」两行基线约在 428 / 448。「Restores the reference document's…」行距 18px，即 12px。G3 没有 13px 常规这一档，建议统一为 caption 12px 或 body 14px（R3 已提）。
9. **200% 下「DOM + GPU」在段内折成「DOM +」和「GPU」两行。** 整个控件高 98px（y=557–654），DOM、GPU 两段被拉成同高。建议每段 `white-space:nowrap`，宽度不够时把整组变成两列网格（2+1），或者收小段内水平内边距。
10. **壳层按钮间距不统一。** 顶栏按钮间距 6px（如 1116–1121），分组间距 20px（模式 → Undo）和 16px（Redo → Save）。预览工具栏按钮间距 8px。390 的动作行混有 5、6、8px。建议统一用一个 gap token。
11. **按钮字重不统一。** 预览工具栏里 Inspect、Focus preview 本轮改为半粗，同一行的 Cards、Responsive 选择器和顶栏的 Undo、Import、Export 仍是常规。建议按「切换类 / 动作类」统一字重。
12. **孤行。** 1440 英文「…discarding later / adjustments.」末行只剩一个词；中文「…放弃之后的调 / 整。」末行只剩一个字。对帮助文字加 `text-wrap: pretty`。
13. **200% Colors 网格的色块和解除列不随根字号缩放。** 色块在 1440 和 200% 下都是 18px（x=45–62），解除列都是 26px，文字已经放大一倍。白色的 background 色块看起来像未勾选的复选框。建议尺寸改用 em/rem。
14. 200% 来源块的 Path 断成「overrides.light.p / rimary」。可在「.」后插入 `&lt;wbr&gt;`，让断行落在点号处。
15. **焦点环对比度。** 壳层焦点环 #A1C6F9 对白底约 1.76:1。G4 本身就规定了「3px 半透明蓝」，所以不扣分。DESIGN.md 若再修订，可提高不透明度，使环对相邻色达到 3:1。
16. 「Overridden · Light 6 · Dark 6」的数字没有名词。可改为「6 overridden values · Light」之类，更贴近 C3 示例「N 项被覆盖」。

## 5. 看不出的格子

- **G2 分隔条**：没有悬停或拖拽帧，看不出 8px 拖拽目标和编辑列 260–520px 的限幅。
- **EN/中文、Edit/Preview 的键盘焦点**：没拍。UI-02 的焦点部分只能用 Light/Dark 帧确认。
- **C2 选项**：U1-keyboard-03 的品牌色列表只露出前 8 项（Custom、Gray、Gold、Bronze、Brown、Yellow、Amber、Orange），数不到 26。中性色、外观、面板、圆角、缩放的下拉都没有展开。
- **G2 ≤800 的「指标改两列」**：U1 帧里没有指标区。
- **768 的 DOM/GPU 上下堆叠**：U1-default-768、U1-configured-768 只看到占满宽的 DOM 区，GPU 区在折线以下，无法确认它堆叠在下方。
- **G3 字体**：字形可以辨认，但截图无法确认字族声明是 IBM Plex Sans，也量不出 18px 标题的 −0.02em 字距。
- **未拍的组合**：200% 与 390 的中文态、各控件悬停态、保存失败后仍能导出（G5，归 U4）。

## 6. 总评

U1 只评这一个单元，9.8 分，比 R3 的 8.7 有明显提升。R3 的 12 条差距中 11 条已解决，UI-02 部分解决。剩下两条都是 P3：

- UI-02 只差 EN/中文、Edit/Preview 的接缝画法；
- 新-1 是中文诊断标题的 CJK 字重。

两条都能在组件样式层修好，不需要推倒布局、换组件或重做素材。

需要留意的是本轮新出现的两个视觉层级变化：「Download current theme」改成实心主按钮，存储状态块变高并把预设区下推。它们不违反规范要点，所以只列为建议 1、2。如果维护方认可 G3「蓝色只用于选中与焦点」的严格读法，应把这两条和顶栏「Save locally」一起处理。
