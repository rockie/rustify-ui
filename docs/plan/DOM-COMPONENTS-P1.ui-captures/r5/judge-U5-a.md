## 3. 未关闭差距

### UI-76 · DOM/GPU 比较框首行起点仍不一致

- **单元与位置**：U5，R5 `U5-gpu-compare-1440-light.png`，DOM 框的 “Local demonstration…” 与 GPU 框的 “GPU · Cards”。
- **维度 / 严重度 / 可挽回分**：布局 · **P3** · **0.05**。
- **现状 → 期望**：两框上边框同高，但 DOM 首行约从 x=357、y=353 开始，GPU 首行约从 x=915、y=357 开始；相对于各自边框，横向内缩约为 13px 与 25px。纵向差缩小，横向对齐回归。期望两框首行具有一致的比较区内缩和垂直起点；沿用 R4 UI-76 对齐口径，对应 G1 的预览区域结构与 P5 的 DOM/GPU 比较排布，不要求内部组件布局相同。
- **具体修法**：调整 DOM+GPU 比较视图两侧的首行容器，使标题行采用同一横向内缩及一致的首行基线。可保留 DOM 内容卡片在窄容器中的较小 padding，仅统一比较框首行；避免为对齐首行而整体平移 GPU 内容。
- **完成判断**：同一帧中，两框首行相对于边框的横向距离一致，首行基线对齐。
