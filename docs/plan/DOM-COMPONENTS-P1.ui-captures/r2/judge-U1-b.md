## 3. 差距清单

排序：先按严重度，再按可挽回分。合计 2.2，等于 10 − 7.8。

### 新-1 · [P1] 200% 下粘性头被封顶，关键动作看不见

- **维度**：布局、交互
- **可挽回分**：0.5（布局 0.3、交互 0.2）
- **位置**：U1-zoom200-720-light 编辑列。
  - 头区固定在 y=0–449，底边是 y=449 的一条 #eaecf0。
  - 「Preview mode」在 y≈440–449 被切掉下半。
  - 头区里看不到滚动条。
  - U1-zoom200-export-720-light 遮罩下可见头区内部已滚到「Light | Dark」（y≈0–20），说明头区是一个限高、内部滚动或裁切的盒子。
- **现状**：200% 首屏只看到标题、语言切换、副标题和主题名，共占 450px（视口 50%）。模式切换、Undo/Redo、Restore、Save locally、Import、Export、Local themes 都在可视区外，鼠标用户没有任何提示能找到它们。
  - 本轮能打开导出，是因为脚本对 Export 做了程序 `focus`（见 actions.log「focus Export, press Enter」）。
- **期望**：
  - G5：顶部保留主题名、模式、撤销/重做/保存/导出。
  - G6：200% 下主路径可达。
  - G2：两区独立滚动，不应出现嵌套的隐形滚动区。
- **修法**：
  - 去掉头区的 `max-height` / `overflow`。
  - 只让一条紧凑工具栏吸顶，内容是：主题名 + 状态、Preview mode 分段、Undo、Redo、Save、Export，再加一个「More」菜单收纳 Import、Restore document、Local themes。工具栏用 `flex-wrap: wrap`，间距用 rem。
  - 「Rustify Theme Studio」、副标题和语言切换放回正常文档流，随内容滚走；语言切换也可以并到工具栏末尾。
  - 这样 200% 下吸顶区最多两行（约 130px），不再需要封顶。
  - 这是结构调整：现在的「整块头吸顶」要改为「单行工具栏吸顶」。

### 新-2 · [P2] 390 编辑页滚动后，内容从标签条与粘性头之间透出

- **维度**：布局
- **可挽回分**：0.15
- **位置**：U1-configured-390-light。Edit/Preview 标签条底边约在 y=46，粘性头标题字形从 y≈86 开始；中间 y≈69–73 露出滚动内容「Presets … 44」的上半截字形。
- **现状 → 期望**：滚动内容从两层固定区之间的空隙漏出来，和标题叠成两行字。期望编辑壳稳定、不遮挡、不穿透（G1、G2 ≤600px）。
- **修法**：
  - 把 Edit/Preview 标签条和工具栏放进同一个粘性容器：`position: sticky; top: 0; background: #fff; z-index` 高于内容。
  - 或者把工具栏的 `top` 设为标签条高度（用 CSS 变量）。
  - 两者之间的间距用粘性元素自己的 `padding-top`，不要用 `margin`，保证整段背景不透明。

### UI-09 · [P3] label、预览标题、选中的字段标签页没有呈现 600 字重（仍存在）

- **维度**：视觉
- **可挽回分**：0.2
- **位置**：U1-configured-1440-light 中的 Appearance、Brand color、Neutral color、Preview mode、Presets；U1-default-1440-light 预览区的「Preview」；U1-field-tabs-1440-light 的「Colors」。
- **现状**：
  - 字号对了：label 的大写字母高 9px，约 13px；「Preview」字母高 11px，约 16px。
  - 字重不对：label「Appearance」每像素宽的墨量是 2.73，同尺寸的选择器值「Inherit」是 2.69，两者实际相同，都是常规字重。
  - 「Preview」看上去是 500。
  - 选中的「Colors」和未选的「Typography & other」笔画粗细看不出差别。
  - 中文态的「外观」「预览模式」明显是粗体，中英文字重不一致。
- **期望**：G3 要求 label 13px/600、预览标题 16px/600；G4 要求选中的字段标签页 13px 半粗。
- **修法**：
  - 确认 IBM Plex Sans 的 600（SemiBold）`@font-face` 已声明，并作为独立的静态 woff2 放在 public 目录，不嵌入 WASM。中文正常加粗、英文不加粗，说明 Plex 600 字面很可能没有加载。
  - label、预览标题和 `[aria-selected=true]` 的字段标签页用 `font-weight: 600`；未选标签页用 500。
  - 自检办法：label 的墨量应比同尺寸常规文字高 20% 以上。

- **修法**：按钮用 `min-height: 2.25rem; padding: 0.375rem 0.75rem`，单位与字号一致都用 rem。

### 新-6 · [P3] 同一行控件高度混用

- **维度**：布局
- **可挽回分**：0.05
- **位置**：
  - 1440 预览工具栏：Cards / Responsive 36px，分段组与 Inspect 28px，Focus preview 38px。
  - 头区：EN/中文 38px（y 16–53），Light/Dark 28px（y 127–154）。
  - preview-390：同一行里 Inspect 26px，Focus preview 与 Back to edit 38px。
- **修法**：壳层控件统一一档高度（例如 32px，200% 下随 rem 放大），分段、切换按钮、选择器、普通按钮都用这一档。

### 新-11 · [P3] 两种焦点环颜色

- **维度**：细节
- **可挽回分**：0.05
- **位置**：keyboard-01 预设搜索框的焦点环是 #8ab7f7；keyboard-02 品牌色选择器的焦点环是 #a1c6f9，透明度不同。
- **期望**：G4 规定 3px 半透明蓝、2px offset，全壳层统一。
- **修法**：所有壳层控件共用同一个焦点环 token。

### 新-12 · [P3] 顶部「Modified」有歧义，吸顶区没有保存状态

- **维度**：交互
- **可挽回分**：0.05
- **位置**：
  - top-1440-dark：头部显示「Graphite Modified」，下方状态框却是「Saved on this device」。
  - configured-1440 滚动后，保存状态已经滚出视野。
- **现状 → 期望**：「Modified」容易被读成「未保存」。C3 期望「配置已选择，N 项被覆盖」这类说明；G5 要求保存状态以实际结果为准。
- **修法**：
  - 头部改为「Modified from preset · N overrides」。
  - 在吸顶工具栏里加一个紧凑的保存状态胶囊（Saved / Memory only / Saving），状态文字取自实际写入结果。

### UI-12 · [P3] 自动配对的中性色名称小写且没有本地化（部分解决）

- **维度**：细节
- **可挽回分**：0.05
- **位置**：
  - configured-1440：「Resolved neutral: mauve.」是小写，而选项是首字母大写。
  - zh-configured：「已解析中性色：mauve。」没有翻译，而品牌色显示为「粉色」。
- **修法**：auto 的解析结果用与下拉选项相同的本地化显示名：英文「Mauve」，中文用选项列表里的同一个译名。

## 4. 建议（不扣分）

1. 默认首屏里，存储状态块（Memory only 框、pending、Cache backups）排在 Presets 之前，「Theme configuration」被推到 1440 的 y≈871。C1 的顺序没有违反，但可以把存储状态压成工具栏里的一枚状态胶囊。
2. 品牌色、中性色选项前可以加色块，便于快速辨认。
3. keyboard-04 从品牌色选择器到 Dark 用了 116 次 Tab。可以加跳转链接或 landmark（「跳到预览工具栏」「跳到基础配置」）。
4. 200% 导出对话框滚动时，标题和关闭按钮会一起滚走。可以让对话框头部吸顶。
5. Import、Export、Use configuration values、Favorites 等次级动作是蓝字蓝边，与 G3「蓝色只用于选中和焦点」有张力。上一轮没有因此扣分，本轮尺度保持一致；可以统一改为中性描边。
6. label 旁的「• Custom」胶囊和选择器里的值「Custom」重复了，可以只保留一处。
7. 以下属于其他单元，只记录不扣分：
   - 中文态 GPU 场景的 Workspace、Overview、Activity、Color tokens 没有翻译（U5）。
   - 768 下预览卡片里的开关贴住卡片右边框（U5）。
   - 0 pending 时「Retry retained saves」「Cancel pending writes」仍是可用样式（U4）。

## 6. 总评

- **最低分单元**：本轮只评 U1，7.8 分（上一轮 6.8）。
  - 上一轮的结构性问题已经修好：浮签遮挡、顶部缺主题名和模式、切换按钮无法区分、语言切换被裁、下拉面板过窄、390 残带。
- **主要失分**：都来自本轮新加的「整块头吸顶」：
  - 200% 下头区封顶在 y=449，裁掉「Preview mode」，并把模式、撤销、保存、导出藏起来（P1）。
  - 390 下滚动内容从标签条与头区的空隙透出（P2）。
  - 1440 下吸顶区占 35%，390 下占 38%（P2）。
- **其次的失分**：
  - 英文 600 字重没有呈现，很可能是 Plex SemiBold 字面没有加载。
  - 辅助文字灰色用错。
  - 禁用按钮与可用按钮的轻重倒置。
  - 未选分段带蓝内框，状态胶囊借用选中蓝。
- **需要结构性改变的地方**：
  - 把粘性头改成单行紧凑工具栏：主题名 + 状态、预览模式、撤销/重做、保存、导出，其余收进 More 菜单。
  - 产品名、副标题和语言切换放回文档流。
  - 工具栏与 390 的 Edit/Preview 标签条放进同一个不透明的粘性容器，并在两个标签页共用。
  - 这一项能同时解决新-1、新-2、新-3 和 UI-03，共可挽回约 0.85 分。
- **其余项**：都是 token、字重和间距的局部修正，不需要换组件。
