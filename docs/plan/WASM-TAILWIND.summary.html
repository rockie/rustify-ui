1. 一句话定位

用 Rust 写一套 cn（className merge）、scanner、Tailwind v4 兼容 compiler，编译成 WASM，在浏览器里 module Worker 跑；JS 侧 UtilityScope 接收类名、CSS scope、DOM 类和组件上下文，吐回 CSSStyleSheet + 有限 GPU 投影，实现 动态 utility 编译，替代 Tailwind 的 JS 编译管线。所有权 从生产端到浏览器都来自 Rust，cn 0.4.0 与 Tailwind 4.1.13 的运行时与 registry 被冻结进测试，组件迁移、scope 变换、配置事务与 GPU 真实绘制都已在 strict CSP、Chrome 154、macOS arm64 / Apple M5 Pro 下回归。

2. 做出了什么：按里程碑拆

七步走，按时序归并到一起。每一项都对应一份记录（docs/validation/wasm-tailwind/M{1..7}.md），这里只挑要做的事与结果数字。

§2.1 M1 · 锁基线 + 拆风险门

  • 把 cn 0.4.0 的 947 runtime / 5 compiler / 25 validator / 3 cache / 12 build、Tailwind 4.1.13 的 1,171 utility roots / 88 variants、scanner 抽取闭包与 125 旧组件输出 全部锁进 tests/utility/，固定 oracle；仅证明快照完整，不是兼容通过。
  • 提供严格 CSP / 单线程 module Worker 的真实 Chrome baseline：5 项 通过，0 CSP 放宽，含 baseline-desktop.png / baseline-mobile.png 截图。
  • V-11 描述性测量：scanner facade 完整产物 58,000 bytes，p50 .4 ms / p95 .5 ms；CSSOM replaceSync p50 0 / p95 .1 ms；既有 fusion 119 帧 p50 8.3 / p95 9.1 ms。固定 JS 上游，不是新 Rust 性能。

§2.2 M2 · cn + 组件迁移 + 完整 Scanner

  • crates/rustify-style/src/cn/ 纯 Rust 默认表 / tagged 输入 / 条件拼接 / 验证器 / 主题 callback / 表编译 / JS·TS 输出 / token subset / build 核心 / 有界缓存。组件 cn::class_variants! 与 IntoTailwindClass::raw_class 保留原始片段，组件只在 caller 最后合并一次。
  • scanner 共享真实 + 虚拟源树的选择 / ignore / glob / 增量 / 位置；24 共享 corpus native/WASM 相同；plain WASM imports=[]，sharedMemory=false。
  • 旧包完整删除（用户明确决策，取代原 F-01 保留建议）：mbx tree --workspace --all-features --target all --edges normal,build,dev --locked 验证全 workspace graph / 锁文件 / 组件源码 / 公开导出无 tw_merge。
  • 数字：cn native 13 / scnner native 124 / 组件 90 / core 164 / facade 2 全部通过；74 历史输出差异仅"新增原本错误删除的 ring 颜色"，无 token 被改。生产 cn bundle frozen 714,887 bytes、生产 host 56/56、947+56 runtime、31 native、2 项 strict clippy；WASM 当前 2,137,348 bytes（SHA cd39e9bf…f0b）、JS 43,725 bytes。

§2.3 M3 · 第一条动态 DOM 编译路径

  • UtilityScope 接收 ScopeRoots 与调用方正数 limits，独立 module Worker 跑 CompilerSession。
  • 路径：prepare → staged CSSStyleSheet → adoption → 主线程快照 → ack。CSSOM 失败 nack 保留旧快照；ack 丢失用已安装快照恢复；retry 用新 epoch 重放。
  • JS 只调 Web API、校验传输身份、操作 CSSOM、清理资源；MutationObserver 读 classList 与新增子树，不调 extractor。dispose / abort 用 JS bound cleanup 终止 Worker、断开 observer、清理 stylesheet / owner；trap 清理不依赖 Rust Drop。
  • 数字：SDK 228 项 通过，3 项 RED→GREEN 是真实队列回归；root + subpath 浏览器 9 + 4 项通过；WASM 1,183 通过 / 0 失败（partial slice，非 V-5 完整）。

§2.4 M4 · 固定版本 compiler 兼容范围

  • 把 upstream tailwindcss 34 个测试文件 / 1,398 项 逐条入账：1,183 rust_passed / 0 failed / 173 excluded_js_module / 33 excluded_js_helper / 7 excluded_js_api / 1 checked_internal_entry / 1 upstream_skipped。
  • 三组门 compiler-api / compiler-slice / compiler-upstream 串行通过：216,133 CSS / 1,607 metadata / 3,002 error / 6,673 variant JSON（host 数字）；实际 WASM 仍跑 216,133 CSS / 4 UTF-16 / 1,607 metadata / 3,002 errors / 6,673 variantParse。fix-bench seed: 889 root 任意分批/乱序/插入 discard 后逐字相等官方 union CSS，5,000+ 候选分批 == 一次性结果。
  • 6 个阶段历史保留：raw 归一化 / theme publication / variant ownership / raw functions / upstream exec / M4 final。每个阶段都把"上一个阶段未达成的"列为不声明项，例如完整 setup allocator 峰值、captured host 投影、单一 ownership 移交。
  • V-11 描述性：variant 构造 p95 +12.39%（同负载不可归因），+91.7% 在 16 个 nested variant/custom 模板下；raw theme 构造开销 +15.6%，全部 pending 定位。

§2.5 M5 · GPU utility 求值与实际控件

  • GPU 给 cascade / state / 主题 / layout / Button 默认值与文字基线；DOM/GPU 真实 137×72、padding 7、#123456 / #abcdef 像素采样通过（Canvas2D 与期望 RGBA 偏差 ≤ 2）。
  • 嵌套 custom 目标在 DOM 生效，GPU 严格拒绝并保留上次成功绘制（computed / applied / drawn），移开指针恢复 DOM 边框。文字 / None 基线（行盒换行差异 + GPU 单行裁剪）作为 M5 未完项保留。
  • 自 2026-10-08 文字换行行盒落地后再次复验：root49 + deep44，0 skip / flaky / unexpected。

§2.6 M6 · SDK 扫描集成 + 评审修复

  • 扫描器：UtilityScope::scan_content / scan_sources 接入共享 FIFO，保序，仅相邻直接类名批次合并；安装前验证 CSS、完整报告缓存与合并候选；失败保留旧 snapshot，ack 丢失保留新 snapshot 并以它 retry。生产 bundle 默认 compiler-only，--utility-scanner 显式启用。
  • 配置事务：UtilityScope::replace_config 先合并登记的 raw 片段，保留 callback 在主 realm；同 epoch supersede 旧队列，事务持有预合并结果，提交不重复调 callback。ack 丢失不回退已安装状态；flush() 是 FIFO barrier。安装失败 / 配置回调 / CSS 配置均保留旧 class / CSS / programs。
  • 评审修复承担在 M6：见 §3。
  • 收口：root53 + deep47（compiler-only），5 + 5（scanner）；cn JS/WASM crossing 947/947；demo cn 输入 / 语言（中英 / navigator.languages）；V-9 边界：候选恰好到上限可装、再多一个 candidate_count 且 revision / 宽度不变，@apply 循环 / ast_depth 嵌套 / 远程 @import 各自返回结构化错误。

5. 当前契约与边界

公开 token 的关键帧值改写规则（当前契约）：当一个 --animate-* 公开 token 只流入动画（如 --animate-card: card 1s …）时，值里的关键帧名仍改为本 owner 名（rustify-<owner>-card），元素上 style.setProperty('--animate-card','none') 可停动画，scope 根上 none 停全部相关动画。当同一公开 token 还要被其他用途（timing、animation-name 列表、动画外的普通引用）改写时，提交前直接返回 UnsupportedFeature（"custom property --x used both as a keyframes name and with another meaning"），保留旧 revision。--tw-* 内部变量仍按 owner 改名并保留副本。

其他边界，全部来自计划与评审：

  • 外部 inline style / 应用自有 CSS / JS 对公开 token 的赋值在 scope 变换时按"未知值"处理；若其后的关键帧名与关键字同名，会报上述 UnsupportedFeature。
  • scope 变换为单 owner，不依赖 Rust Drop 终止 Worker / observer / stylesheet，必须走 JS bound cleanup 路径；trap / 超时需显式 retry + 新 epoch + 重放 committed 输入。无无限自动重启。
  • scanner 默认 不进入主 bundle；生产 bundle 是 compiler-only；要启 scanner 必须显式 --utility-scanner，并以 scanner_enabled=true 重建。Worker 入口来自 main manifest 的协议 export，不混用。
  • flush() 是 FIFO barrier；未安装时初始化空输入，已有安装时返回 snapshot，不重复 Worker 编译。
  • GPU 对嵌套功能分支明确报 Unsupported，DOM CSS 仍完整保留；调用方在安全 props 阶段消费已安装 report；GPU 在等待 drawn revision 时不出错也不假装完成。
  • 性能：plan 没有数值 SLO；M4 raw variant 构造 p95 +91.7% 仍未定位；media/theme 负载下数字仅描述当前负载。
  • CI：R1 F-03 修复后 npm ci --ignore-scripts --prefix tests/utility/compiler/oracle 在隔离目录复现成功；远端 GitHub Actions 未实际运行，不在本轮结果中。

6. 未重验、不能抵扣、未覆盖

这一节是 Wasm-Tailwind 真实风险所在，不要从 M1–M7 / R1–R5 表面数字误判为「全通过」。
  • V-5 完整兼容门：fullConformance / fullUtf16Conformance / fullPublicValueConformance 仍 pending。4 项 legacy UTF-16 boundary 已 unit 相等，但 486 项完整 UTF-16 输入矩阵未通过；non-scalar candidate guards 在 79 / 79 case 上仍 RED，是 V-5 未关闭项。
  • 全 setup allocator 峰值：当前各门记录阈值是 fixture 同步保守边界（utilities 22,324 / theme 40,734 / apply 56,502 / 函数失败 13,794 / apply 失败 28,902 等），不是全局峰值证明。
  • V-11 性能：variant 构造 p95 +12.39% / +91.7%，raw theme +15.6%，均未归因或优化；本轮无 p50 / p95 承诺；测量时系统负载偏高。
  • 远端 CI：GitHub Actions 未实际跑；CI 文件 hash 未变；本轮只用隔离目录复现 oracle 安装步骤。
  • 操作系统 / 浏览器：仅 macOS arm64 / Apple M5 Pro / Chrome 154。Windows / Linux / 其他浏览器未验证；原生 Makepad 窗口按计划排除。
  • Vite HMR / Next 项目：未启动；M2 覆盖生产宿主差分核心，不代替完整项目。
  • scanner 浏览器最新复跑：R1 / R2 / R3 复审有 5+5 浏览器；R4 / R5 复审只跑 compiler-only，scanner 浏览器被列入"未重建并重跑"。
  • Worker 内存：浏览器 Worker 内存需要跨源隔离才能测，目前以 Node 中同一 facade 的线性内存高水位代替，未测。
  • 完整 Source/host 投影：captured host 投影、动态 Proxy / 外部 loader callback、shared 节点 / Source 图全契约仍是未完成项。
  • 完整 helper / 公开 API：compileAst / DesignSystem / helper / source-map / Features / Polyfills / warnings 仍在 fixture / pending。
  • 历史脏数据：所有改动都基于 53652fcc… HEAD 的 dirty 工作树，未提交、未推送、未发布；release manifest 全部以工作树中编译产物为准。
  • M5 缺口：窄按钮 DOM 换行 / GPU 单行裁剪差异保留；文字 / None 基线在 M5 未完项中。
  • 评测生成器：review-r4 / r5 共有 8 + 9 = 17 个反例探针，本总结未复述其完整对照；详见对应 animation-probe.json / cascade-sdk-browser.json。
