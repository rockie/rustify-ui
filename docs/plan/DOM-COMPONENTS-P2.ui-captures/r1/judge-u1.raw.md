### 3. 建议，不扣分

- **原生约束消息语言**：EN 页面中出现“请填写此字段。”，而 rule/application 消息为英文，阅读体验不一致。采集清单明确这是系统原生 validationMessage；目标未明确要求覆盖系统消息语言，因此不据此扣分。可以决定遵循系统语言，或提供与应用语言一致的约束文案，并明确这一口径。
- **FormData 阅读密度**：`U1-saved-data-1440-light.png` 的每个键值占多行，查看完整提交结果需要较长滚动。可以提供更紧凑的键值排布，同时保留原始 FormData 展示。规范没有规定紧凑程度，不扣分。
- **采集时机**：两张保存状态图片的页面读取记录为“Saving locally…”，实际图片已是“Saved in this preview only”。后续应分别固定采集 busy 帧与完成帧，避免把二者混为一种证据。
