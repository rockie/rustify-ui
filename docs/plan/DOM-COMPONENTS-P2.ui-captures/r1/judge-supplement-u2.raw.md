旧 5 条差距逐条复核：

1. **原新-1｜卡片缺少说明｜仍存在｜交互状态｜P2｜可挽回 0.4**

   **图位置：**`U2-RadioCards-s1-classic-1440-light.png`、`U2-RadioCards-s2-surface-1440-light.png`、`U2-RadioCards-s3-classic-1440-light.png`，以及三张对应 CheckboxCards 图；右侧示例中的两张选项卡。`U2-mobile-cards-control-a2-390-dark.png` 中也一样。

2. **原新-2｜soft Switch 关闭态辨识弱｜仍存在｜视觉｜P2｜可挽回 0.5**

   **图位置：**`U2-Switch-s3-soft-1440-light.png`，右侧示例框左端的关闭态 Switch。

   **现状 → 目标：**轨道、拇指与浅色底面十分接近，控件轮廓明显弱于同批 classic／surface；G-2 要求必要非文本边界有足够对比，G-4 要求必要胶囊形状保留。

   **具体修法：**增强正常关闭态轨道或轮廓的辨识度，保留 soft 外观，并与禁用态区分。

   这是直接可见的辨识问题；本次没有测量像素对比度，**不据此断言精确 AA 数值失败**。

3. **原新-3｜Checkbox／Switch 缺少可见用途标签｜仍存在｜交互状态｜P2｜可挽回 0.4**

4. **原新-4｜invalid 反馈仅靠颜色｜不再适用：撤销原扣分｜可挽回 0**

   **图位置：**`U2-CheckboxCards-invalid-1440-light.png`，State 选择器和下方卡片。

   **现状 → 目标依据复核：**卡片本体确实主要通过小复选框红色轮廓表现 invalid，但同一状态工具中的 State 选择器明确显示 **Invalid**，已有非颜色状态信息。冻结的 U2／G 规范没有进一步明确要求此状态演示必须展示业务错误原因。

   **具体修法：**依据真实选择模式添加简短说明，明确可选数量及清空规则；业务值无需翻译或改写。
