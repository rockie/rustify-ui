建议，不扣分：

- raw 空列表增加明确的空内容说明，帮助用户区分“没有选项”和“列表没有成功打开”；目标没有规定具体空态文案。
- 在竖向与反向示例旁显示可见名称和当前值，减少两根无文字轨道之间的辨认成本；截图不能证明其无障碍名称缺失。
- 为取消选择补拍“原值 A → 尝试选择 B → 取消后仍为 A”的完整记录。目前 `cancel-selection` 是在原值已经为 Activity feed 后再次点击 Activity feed，结果与普通同值选择难以区分。

看不出的格子，均不计通过或失败：

- U4：每个 thumb 的无障碍名字和数值属性；preserve_order、间隔限制、min/max/step 边界；Home/PageUp/PageDown 等完整键盘矩阵；禁用/只读是否不发请求；局部 radius、scaling 的效果。
- U4：拒绝操作记录显示 `commit`，但未提供完成事件的候选 payload，不能确认是否交付最后候选；取消记录能确认 commits=0、cancels=1。
- U5：分组标签；Escape 关闭与返回焦点；外点关闭是否保留外部焦点；选择不同候选时取消钩子是否保留原值；禁用项实际不可选择；禁用/只读是否不发值请求。
- U5：长列表已记录 End 和活动项 ID，但叠字妨碍判断活动项的完整可读性；没有滚动位置记录，不能完整确认滚动始终限定于自身 viewport。
- U5：已选项移除后 placeholder 的独立过程；浮层的中文继承；Content solid/soft 的规范化视觉差异未给出精确目标，不能仅因两张浅色图接近而扣分。
