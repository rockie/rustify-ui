## 偏差与说明

- **PanelTabs close 结构按 axe 实测三轮就地修订**（计划 §5.4 已同步改写）：sibling button 触发 aria-required-children critical（presentation 子节点被提升为 tablist 直接可及子节点）；tab 内 button 触发 no-focusable-content serious；span[role=button] 仍触发 nested-interactive serious。终态＝可及树外鼠标 close span（无 role/tabindex/aria-label，`stop_propagation` 防误激活）+ Delete 键关闭活动 tab（浏览器行为用例断言）；Close 消息的 zh 断言随 aria-label 移除而删改（extensions_ssg 同步）。
- 拒绝理由元素 id 改 `id::next` 动态生成：静态 id 在双预览 DOM 中重复，被布局用例的重复 id 检查拦截。
- 样本 PanelTabs 加 `w-full`（fit-content 使 strip 溢出卡片 140px）；`.gallery-workspace` overflow-x:auto 承载窄宽度内滚动。
- axe `include()` 需字符串选择器（本版本对 Locator 序列化失败）；picking 用例局部验证改为 tree-l0 hover（DOM 部件报 inspector-source）+ 局部 palette 以 computed color 验证 token 继承（模态层遮蔽预览工具栏，picking 拦截非 aria-haspopup 目标的点击）。
- resources 循环以「运行命令自关 palette」替代 Escape（Escape 不稳定关闭层并阻塞后续轮次）；20 轮后 stats 数值项≤基线、节点数相等。
- axe/对比/布局在修复链中多轮复跑，最终全绿一次通过于上表 V-2 ③ 运行。
