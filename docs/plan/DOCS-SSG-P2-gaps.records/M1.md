## 偏差（已就地修订计划正文）

- `{ty}`/`{expr}` 显示为规范化 token 的紧凑写法（`Vec<StepSpec>`、`"Counter".to_string()`），只改显示（§5.1 第 1 条）。
- CardGrid.columns 值域是 builtins.rs 自有规则，形状模板会写出 `columns: 0` 而与值域矛盾，改由该模块给“Set `columns` to 1, 2 or 3, or omit it for the default expression `2`.”（§5.1 模板表新增一行）。
- 红基线发现 CRLF 下载荷位置前移（`unknown:` 键报到上一行行尾 41:13、重复键列号 7 而 LF 为 8）：pulldown-cmark 规范化 CRLF 丢掉 CR，旧代码按“首段起点+偏移”换算。V-1 要求 CRLF 格位置一致，故在本里程碑修正（§5.1 第 3 条）。
- 重复键由 YAML 遍历识别，不读 serde_yaml_ng 的错误文本。
- dev 复用代对预检已拒绝嵌入的重复报告（见“交付行为”），§5.1 第 4 条已注明。
- 既有现象（不在本计划范围，未改）：mbx 下工程首次以 Development profile 编译时可能把构建脚本写入 mbx out-dirs 的文件当作输入变化，报 `rust-generation-changed` 并丢弃该代，第二次正常；差异报告的冷反例同此。真实组件测试在良好状态先预热开发 profile（只容许这一种已知结果），再比对 check 与 build（计划 §12 已登记）。
