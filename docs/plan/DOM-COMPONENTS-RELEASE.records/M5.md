1. `/components/` 总索引由 markdown catalogue 承载（CLI `nav-route-origin` 禁止 nav.routes 指向 markdown 页）；2. Select 无分组 API，以级联选择呈现；3. `ThemeBoundary` 在 docs island 挂载 panic（无 ThemeScope，不改 SDK），demo 为静态对照，根/局部/继承比较由公开 Studio Inspector 承担；4. theme.document 使通知宿主经 CSSOM 注入 token（CSP 不拦截），spec `[style]` 断言放行该宿主；5. 设计工具经用户决定以 phoenix-ui 替代 impeccable（已跑 context，基于 PRODUCT/DESIGN 中性壳）。
