## 交付行为与路径

- `primitives/select.rs` 及私有 `select/model.rs`、`select/browser.rs`：Root、Trigger/typed trigger_as、Value/Icon、Content/Viewport、Group/Label、Item/typed item_as、ItemText/ItemIndicator、Separator 与上下滚动按钮共用一套行为。业务值和 open 均由应用持有；active/search 仅为瞬态交互状态。
- entries 的有效身份、禁用索引和归一化定位文本只在数据变化时缓存。显示标签、SSR 和原生镜像消费显式元数据，富内容不改变定位语义。空/重复 entry、重复/未知 Item、缺失 Item/Trigger 均诊断；非法项禁用，不请求非法值。未知/移除的接受值只显示 placeholder，不修改业务 Signal。
- Trigger 保持焦点和 combobox ARIA；只有挂载后的 listbox/活动项才可被引用。方向键、Home/End、Enter/Space、Tab、重复字符定位和 1000ms 缓冲按计划实现。on_select 先于一次值请求和关闭请求；拒绝/延迟接受不改变显示。read-only 可检查、不可请求新值；disabled 不交付请求。
- 单个 visually-hidden 原生 select 只同步接受值，支持 name/form/required。接入已有 Field 与 FormRoot 逻辑注册，真实约束失败定位 Trigger；无额外业务值。关闭 SSR 可显示接受标签与表单值；初始打开通过 StaticRenderIssues 拒绝，公开 record 方法供独立 components crate 使用。
- Content 使用 Leptos AttributeInterceptor，把调用方属性/监听及 Themes 标记送到实际 listbox。默认鼠标处理使用父节点 SDK 冒泡监听，调用方先取消；监听随部件/实例清理。长列表只滚自己的 viewport，整个 Content 在短视口中也受限。
- `rustify-dom/src/overlay.rs`：host/browser Layer 同步增加 Escape/outside、开/关自动聚焦 hooks、direction 和实际 LayerPlacement；中立类型由 core/SDK 重导出。回调在锁外运行，取消的顶层事件不穿透下层，close_top 保持程序请求语义。native composing 保留浏览器默认动作；Draft 取消仍优先于浮层关闭。
- 外点只看顶层及关联 Trigger，真正外点不抢回焦点；自动聚焦可取消。anchor 断开只请求关闭一次并释放注册/观察/捕获，应用拒绝关闭也不保留活动失效层。Mutation/resize/类型定位计时器进入既有 abort/cleanup 边界。
- `select.rs` 的旧 Select/SelectOption 便捷接口改为同一 Root/部件组装，空字符串映射 None。Themes 有 size 1/2/3、五种 Trigger variant、solid/soft Content、局部 color/radius/high_contrast 和响应式几何；无第二份事件实现。SDK 样式只加皮肤，PRIMITIVES_CSS 仅加结构。
- `tests/dom-only` 新增原始与主题样本。`theme-ui-review.spec.ts`、`p2-semantics.spec.ts` 的旧列表焦点/业务值 DOM id 断言迁移到 Trigger 的真实活动项关联；这些示例的 release 回归留 M5 合并执行。

## 必要修正与兼容边界

- 属性透传回归实际先失败；使用框架自带 AttributeInterceptor，未另造适配框架。
- outside hook 的 Some 也启用默认外点关闭；省略时保持旧调用的外点行为。Select 总是提供 forwarding hook，因此公开可取消的 Select 外点关闭生效。
- 初始 CSSOM 几何曾被继承的过渡时长插值；Select 只过渡颜色/阴影等绘制属性，不动画尺寸。
- 截图发现默认深色 translucent popover 透出底层字段，补不透底断言先红后绿。Select Content 将原 popover 颜色叠到主题 background 上；保留作者颜色，不改主题 schema、配置或全局面板样式。
- modal 测试 fixture 显式启用已有 fit，保证真实外点目标可达；不把 offscreen fixture 当产品点击缺陷。
