## 交付行为与路径

- `primitives/slider.rs` 及 `slider/model.rs`、`slider/browser.rs` 提供 Root/Track/Range/Thumb、typed 自定义目标和 ThumbValue/ThumbLabel。现有 `slider.rs` 改为同一行为的 Themes Root、RangeSlider 和单个 value 身份的标量 Slider；保留旧标量回调，新增 commit/cancel。
- 数值按 min 基点/step 规范化，只投影到绘制、ARIA 与 hidden accepted inputs，不回写业务值。候选按数值排序、等值按首次声明排序；DOM 与 Tab 身份不跟数值排序移动，新增追加、删除移除。最小间隔、preserve_order 邻接界限、非法配置最后有效显示/禁用与初始可读错误共用计算层。
- 仅接受值驱动外部 CSSOM/SSR 几何；指针会话保存开始值和最后请求候选，拒绝/延迟时不显示候选。pointerup 与键盘序列结束只提交一次；Escape、取消/丢失捕获、活动项失效及 cleanup 结束临时资源。原生捕获有绑定的 JS release_on_abort，resize/scroll 用现有 runtime 资源入口。
- 轨道矩形在手势中缓存，实际 ResizeObserver、窗口 resize 和 scroll 使缓存失效；move 不反复测量 DOM。身份/声明顺序通过 Arc 复用，数值邻接未变时复用位置索引；有序接受向量跳过全量排序，候选只移出活动项、二分插入和检查两侧间隔。Themes 的 For 只在声明顺序变化时更新；每个 Thumb/Range 的独立 memo 过滤无变化的几何。
- `css/form-controls.css` 增 Slider 皮肤（size 1/2/3，classic/surface/soft、局部 color/high_contrast/radius）；`primitives.css` 仅增结构定位及保留另一轴滚动的 touch-action。Slot 增私有 owned class token，防止几何 class 覆盖 typed 目标原有 class。
- 独立无皮肤消费者增加 `sliders.rs`；标量 benchmark/current 消费者补可访问名称。Studio 的现有 slider 接入真实 label ID；原有 SSR、hydrate、Catalog/Studio slider 与性能 driver 的原生 range 断言/驱动迁移到新部件。baseline 产品和冻结源码未覆盖、未重测。

## 必要修正

- 补“拒绝预览后回到接受的开始值”用例先红：不能因为候选等于接受值就丢弃它、留下旧 last request。允许该候选进入会话，并跳过首次无变化请求；最后回到开始值时不 commit。
- 活动拖拽中的 scope 销毁测试先失败：Owner 已释放后 DOM remove 仍发 focusout。事件归属与捕获结束入口使用 try 读取，已销毁的边界直接忽略；同一真实销毁测试现通过，runtime tasks/timers/observers/errors 均回到 0。
- SSR 的 For 在 Root 开始标签之后才展开项，不能按当时未展开的部件误诊整个值集缺失。数值/键校验保持独立，实际声明的 Thumb 校验名称；最终 SSR 的标量/范围与正常表单镜像测试通过。
- 首次裸 `mbx check` 省略 build-web 的 web_sys_unstable_apis，Studio 既有坐标/滚动代码因此遇到 i32/f64 类型错误；读取 xtask/build.rs 与 web-sys 声明后按同一 cfg 重跑成功，没有修改这些无关源码。
