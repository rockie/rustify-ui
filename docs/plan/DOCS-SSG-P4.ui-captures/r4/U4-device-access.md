# R4 · iPhone 原生资源接入记录

- 用户先确认“有 iPhone，Safari也有”，随后确认“本地的iPhone镜像已连接好”。本轮实际通过CUA绑定了本机iPhone Mirroring窗口，观察到实体手机界面。没有把Xcode列出的模拟器充当真机。
- 接入初始画面属于手机原有应用，未保存为本任务证据。通过镜像主屏幕快捷键和Safari图标尝试进入；未编辑、提交手机原有页面上的内容。普通坐标点击、typeText和粘贴没有稳定达成所需输入，因此未记为产品任务成功。
- 本轮为手机启动相同官方构建的局域网preview：`http://192.168.16.192:4199/rustify-ui/zh/`；服务使用仓内固定CLI的`--host 0.0.0.0`，不部署到外部、不安装软件。用户已收到在Safari新建标签打开该入口的请求。
- 随后镜像明确显示“iPhone使用中”，提示因iPhone被使用而结束镜像、需锁定后连接；[窗口实拍](U4-iPhone-connection-state.jpg)。本轮点击原生“连接”恢复已有授权会话后，实际又出现“iPhone麦克风使用中”的等待提示。
- 再次核对时，最新状态为“已超时 因连接期间iPhone被使用，iPhone镜像超时。连接前请锁定iPhone。”；[最新窗口实拍](U4-iPhone-timeout-state.jpg)、[原生AX](U4-iPhone-timeout-state.ax.txt)。未自动结束手机上的麦克风活动。
- 目前没有任何文档站的iPhone实机页面图、软键盘交互或结果导航证据。以上只有环境接入证据，不是产品UI差距或手机验收通过证据。
- 继续条件：iPhone结束麦克风占用并锁屏，恢复可操作镜像；在真实Safari上进入本轮固定产物后，按原目标采阅读、导航、搜索、主题与软键盘等任务。手机型号/系统版本/CSS视口也须从实际会话补齐，不能从镜像窗口像素或模拟器名称猜测。
