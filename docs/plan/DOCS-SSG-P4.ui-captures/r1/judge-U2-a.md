2. **差距清单**

**新-1｜P3｜可挽回 0.2 分：375px 视口的对话框宽度少 6px。**

- **证据与位置：**`U2-loading-375-light.png`、`U2-module-error-375-light.png`、`U2-module-retry-375-light.png`、`U2-index-error-375-light.png`、`U2-index-retry-375-light.png`，整个搜索对话框及内部输入、结果、Retry 区域。
- **现状 → 期望：**对话框边界从约 x=19 到 x=355，外宽 337px、左右各约 19px；S1 明确宽度为 `min(36rem, viewport − 2rem)`，在 375px 视口应为 343px、左右各 16px。现有内容区因此也少了 6px。
- **具体修法：**调整原生搜索 `dialog` 的宽度与 `max-width`，显式落实 `width: min(36rem, calc(100dvw - 2rem))` 及相应最大宽度，并使用 `border-box`；保留窄屏 1rem 内边距。复拍五种状态，确认外宽 343px、输入和按钮随内容区扩展，桌面仍为 576px。
- **计分归属：**细节 0.2 分；不重复扣布局分。

可挽回分合计 **0.2**，等于 `10 − 9.8`。未发现有证据支持的 P0、P1 或 P2 问题。

3. **建议，不扣分**

- 六张结果状态截图均显示 **“1 results”**，建议英文总数使用单复数模板，单个匹配页面显示 **“1 result”**。目标包 S2/S3 规定了总数的存在和计数含义，没有规定英文单复数模板，因此按本轮比较口径列为文案建议，不扣分。
- 无需新增错误插画、警告色、加载骨架或第二套恢复布局；现有简短状态与 Retry 已符合 S4 的明确要求。

4. **看不出的状态及证据缺口**

- **规定截图矩阵完整：**13 张图片均已打开，清晰可读，没有缺图或无法识别状态的格子。
- **错误状态的完整键盘路径：**记录只有点击 Retry，没有 Tab 抵达 Retry／Close、键盘激活及其焦点外观，不能确认这些操作满足 G3/S3。
