## 决定与未完项

- Google 示例的来源取自 2026-10-21 读取的 Google CSP 指南（GA4 含广告功能 + Google Ads 转化与再营销的并集），并写明 `www.google.<TLD>` 要逐个列出。
- 两个厂商示例都加了 `form = ["https://leads.example.com"]`：V-8 首轮把页面示例（含表单）放到厂商配置下，`check` 报 `form-origin`，说明示例不能组合使用，补上后组合可用。
- 百度示例只列 `img = ["https://hm.baidu.com"]`（脚本 origin 自动并入），是 A-2 的假设；Google 示例的自托管初始化是 A-1 的假设。两者都要在 M5 的 V-13 中用真实脚本核对后定稿，本里程碑不宣称已验证。
