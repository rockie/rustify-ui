## 独立角色模拟（Agent，不是真人数据）

角色只依赖公开 themes/migration/consumer README 以及生成的 JSON、Rust 与接入说明来选择入口；不借内部实现补缺失步骤。公开 README 原来没有修订注入命令，按旧步骤会在 generator 的 env! 处失败；本轮补入已定命令，并在计划文件清单登记该说明修订，构建脚本和契约不变。

按其 DOM-only 入口生成并编译原 Rust/JSON。所选预览 Light，context=font_context(16., false)，base=/；同一原函数的显式 Dark 与普通作者 Dark 由独立运行用例核对。生成的 [consumer-setup.txt](../../validation/dom-components-p1-gaps/export/consumer-setup.txt) 和 [consumer-theme.json](../../validation/dom-components-p1-gaps/export/consumer-theme.json) 可带走；普通挂载遵守 appearance=dark，显式 Light/Dark 不回写文档。Studio 真下载 Rust 去掉唯一修订 header 后，与该消费者编译的原片段逐字节相等。

说明中的两模式字体逐一列出请求、有效族、resource_path；去重复制集合包括 glyph fallback。独立消费者下载到真实同源 ttf，且目录复制原 FONT-LICENSES.md 与其许可；字体未进入 wasm。Studio 资料和独立资料修订均为 b9d5d356d00ebef4d387e0753cf14e2d8917ea9e；差异仅为本用例选定的 context/文档，未混用 registry 0.2.1。
