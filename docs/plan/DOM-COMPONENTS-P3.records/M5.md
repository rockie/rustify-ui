## 交付

按 §5.5 实施 DOM 路径：原生 img、table、dl 与真实 scrollport。Avatar、AspectRatio、Separator、ScrollArea 提供原语；Badge、Callout、Card、DataList、Table 是 Themes 静态内容，不另建无实际用途的 raw API。Avatar 的原生图片代次/缓存 attachment 检查与可撤 fallback 延迟共享同一呈现状态，SSG 保留可读 fallback。AspectRatio 拒绝非有限/非正值并保留最近有效几何；Separator 默认装饰，语义方向与浏览器响应式方向同步。

Badge/Card 的 typed native 装饰保留标签、属性、子项与监听；Card 不增加激活行为。Callout 仅显式 status/alert 才宣告。DataList 保留 dl/dt/dd 和多个值；Table 保留 caption、原生行列表头及 headers/跨度，横向溢出交给外层局部 scrollport。各自尺寸、变体、布局、Margin、颜色/高对比和适用半径沿现有 geometry/组件颜色契约实现。

ScrollArea Root/Viewport/Scrollbar/Thumb/Corner 共用原生 scrollLeft/scrollTop，不移动一份模拟内容。单帧批量度量 viewport/content/tracks；模型统一处理 18px 最小 thumb、track 上限、逻辑 RTL 距离与抓取偏移。拖动只持有短监听和 pointer capture；ResizeObservation、frame、timer 随正常 Owner 清理和 abort 释放。Auto/Always/Hover/Scroll 与轴开关保持同一事实；Viewport 保留原生键盘、wheel、touch/inertia，Boundary 只决定 overscroll。事件归属比较真实 Root 节点，作者 id 不影响嵌套区域隔离。

便捷 ScrollArea 的 `test_id` 继续指向 Viewport，`class` 布局约束落 Root，另有 `{test_id}-root`；benchmark 高度选择器已迁移。被替代的旧原生滚动条皮肤已删除。结构规则只进 PRIMITIVES；外观合并为 `content.css`/`styles::CONTENT`，SDK 与 Docs 虚拟资产均已登记。目录和迁移指南同步实际入口；source 改动未包含在公开 0.2.1 中。

两消费者新增折叠内容工具、URL SVG 资源和内容样本，raw 仅使用实际原语；styled 主任务 Details 组合 Avatar/DataList/Table 与既有选择卡片。`content.spec.ts` 准备 13 个用例，覆盖参数矩阵、图片竞态、真实滚动/清理、原生语义和 FormData；本批仅完成登记与解析，真实浏览器留 V-8/M7。
