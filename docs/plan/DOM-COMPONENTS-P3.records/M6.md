## 交付与契约

本批为 DOM 路径。core toast Provider/Viewport/Root/Title/Description/Action/Close 是唯一行为源，raw 重导出、Themes 与 Toaster 只加外观。ToastHandle.items 映射同一 Root；body 在 Root Owner 中构造，避免缺 context、重复 Root/计时。FIFO/Replace、限量/持久项、拒绝关闭、单调剩余时间、暂停原因与一次最早到期 timer 共用 Scheduler。两条常驻 polite/assertive 宣告通道仅在获得可见槽时投递；批次替换文字不累计历史。

通知继续接入现有 overlay 的父引用/宿主迁移；LayerRecord 保存创建 Viewport 的稳定 Owner 引用，迁移不改变 Provider 归属。聚焦通知的 Escape 在父 modal 前处理、通知子层优先、原生编辑优先；不另建全页键盘监听。Viewport 及后代 hover/focus 暂停同 Provider 全部可见项，window blur/hidden 全局暂停，swipe 暂停所属项。结构隐藏/touch-action/announcer CSS 放两个 runtime stylesheet，保证仅 core 的旧消费者同样具备规则。

Progress 保留原单位 ARIA，百分比只用于几何；未知或非法值不伪报完成。Spinner/Skeleton 共用 loading 投影，保留原节点/草稿/listeners，通过 inert/aria-hidden 控制隐藏交互。结束时恢复可达性，不异步抢回外部焦点。typed Spinner 适用于可合法插入 status sibling 的 flow parent；表格内部应选合法容器。typed Skeleton 装饰 replaced element 时保留空白盒，需可见占位可包容器。loading/status/通知区/关闭文案使用 locale。

旧 ToastOptions 字面量、静态示例 Callout、site Tooltip typed trigger、Vellum 自有展示及原生到期/abort 测试已迁移。两消费者反馈样本与真实原生 timer 探针已接入。构建发现的泛型 Action 闭包解析问题以表达式括号修正。公开指南、最终能力表及完整任务由 M7 收口。
