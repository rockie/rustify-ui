## 交付与边界

本批交付 DOM 路径，依据计划 §5.4。Popover、HoverCard、Tooltip 与 M3 Dialog/AlertDialog 共用 `primitives/floating.rs` 和 core Layer；GPU 仅回归旧 Region anchor/输入，不新增 GPU 组件。应用仍拥有 open，组件只发请求；拒绝和延迟接受不会产生暂时的显示状态。

原语增加 Popover/HoverCard/Tooltip Root、原生 typed Trigger、Portal/Content/Arrow；Popover 支持显式 Anchor，保持 Trigger 的实际开关及回焦语义。HoverCard 保留原生链接；Tooltip 保留 authored aria-describedby，关闭只移除自己的关联，诊断交互内容并始终不移动焦点。Provider 只向 Tooltip 提供打开/跳过延迟与 hoverable 策略。悬停计时可撤销，grace 仅在实际指针跨越间隙时监听；相反输入、Escape、失效 Trigger、卸载和实例 abort 释放所属资源。focus outside 与 blur 复用一个可取消决定，不重复关闭。

core 的定位任务按 dirty 合并为一帧，Optimized 空闲不持续测量，Always 才逐帧更新；实际 Arrow 尺寸进入同一个 placement 计算，物理 side/align、anchor/available CSS 变量与箭头坐标来自同一结果。detached 时保持 controlled open、隐藏并退出交互注册，恢复后重入；帧句柄、ResizeObservation 随 active/Owner/abort 清理。旧 Element/Region anchor 路径保留。默认恢复焦点使用 preventScroll，避免把已离开视口的 scope 滚回。

Themes 提供 Popover 四档、HoverCard 三档、Dialog 四档与 Tooltip 的宽度参数；Layout/Margin/响应式几何、局部主题/方向和 caller utilities 复用既有 geometry。语义 popover 颜色若带透明度，先与当前 background 合成为阅读面板表面，避免叠层文字透出；Arrow 继承实际面板背景。结构 CSS 留在 PRIMITIVES_CSS，外观集中于 PANELS，Docs 虚拟 CSS 资产已登记 panels.css。

Tooltip 便捷入口改接单个 native `trigger`，仓内 consumer/benchmark/hydrate、Docs fixture 和 component-catalog 同批迁移。迁移指南、架构、目录与生成 CSS 已同步；完整公开 panels 指南与最终能力表仍属 M7。

两消费者的 `stage_panel.rs` 提供同语义完整本地任务：Tabs/Accordion/Collapsible、保留编辑草稿、Dialog → Popover → Select、保存/取消、安全删除/恢复。测试探针另覆盖接受/拒绝/延迟、失效部件与资源，不把 fixture 当成新增业务产品。

## 验收发现与修复

- 同值 Signal 仍通知：detached=false 重写导致 ResizeObserver 重建→回调→下一帧的空闲循环；pending=false 重写导致拒绝关闭/移除 Trigger 时自触发。仅值变化才投影，实际 idle/关闭测量为零，移除仅发一次失效关闭。
- 共享 blur 与 FocusOutside 曾重复请求或覆盖取消；blur 使用可撤销的零延迟候选，由 core outside 决定取消候选，保留程序 blur 的自然关闭。
- 全局 motion 规则直接向每个 data-name 元素设置非零 transition-duration，使默认 transition-property:all 将 Content 与标题栏的继承 visibility 也过渡。浏览器记录确认：首焦点回调时标题栏 computed visibility=hidden，Close 因而不可聚焦。规则改为提供 utilities 的 `--tw-duration`，不替无显式过渡的元素开启动画；旧 Dialog 焦点/关闭用例先红后绿。移除了无效同步 CSSOM 呈现实验与临时诊断脚本。
- Playwright 假时钟 ID 超过 web-sys i32 原生句柄范围，产生清理后的回调；测试改观测原生计时/取消与真实等待窗口，不给产品添加假时钟兼容层。
- 受控拒绝关闭且 Anchor 移除后，面板已隐藏但显式 visibility:visible 的 Arrow 仍出现；新增实际 Arrow 隐藏/恢复检查先红，将正常 Arrow 改为 inherit，让祖先隐藏生效，碰撞隐藏仍显式 hidden。
- 原生 focusin/pointerenter 不可取消；组合测试使用明确可取消的合成事件检验契约，实际 click 取消单独验证。不以无法 preventDefault 的原生事件证明取消失效。
