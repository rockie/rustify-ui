## 修复与必要接缝偏差

- SSG 序列化可能在兄弟项之间释放前一项 Owner；root registry 因而保留自有 String key，浏览器随 Item cleanup 注销，host 随 Root 释放，避免后一重复项误判或访问已 dispose 的 StoredValue。
- `reordered live` 浏览器用例先红：登记顺序与 DOM 重排不一致，且移动同一 DOM 节点会失焦到 body。改为实际顺序与树变化观察，在焦点原属本组、节点仍有效且失焦时恢复；真实移除/禁用再按原位置选择。
- TabNav 的普通链接曾被现有 owner/guest router 委托拦截，fragment 不到浏览器。为落实已定原生链接要求，新增唯一生成标记 `data-rustify-native-navigation`，anchor_target 仅对该标记跳过 scope 路由。普通 SDK 链接契约保留，没有新增路由框架/配置或宿主协议；计划 §1.2 与 architecture.md 已同步，最终公共接缝回归纳入 M7。
- 参考 segmented-control.css 的外高是 space-5/6/7、内边距 space-3/4/4；修正初版多出的 root padding 和尺寸 1/2 的水平内边距，默认实际外高已实测为 32px。
